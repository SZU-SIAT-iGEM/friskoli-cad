# 当前项目与后续开发顺序

更新：2026-09-29。本页记录开发安排；实际完成情况和验证数量以 [PROGRESS.md](../PROGRESS.md) 为准。协议层的版本边界、迁移规则和新增接口集中写在[协议扩展计划](protocol-expansion-plan.md)。每完成一步，先检查结果和限制，再更新这两处及相关说明。

## 现在有什么

Friskoli-CAD 目前有**可从源码运行的后端数值核心、版本化协议、可编辑工作区与本地结果回放**。行为图连接带形状、物理量、单位、物种与时间语义的模块；编译器检查连接并确定执行顺序。单菌体有稳定 ID、位置、朝向和可选的胶囊尺寸，`0.2.0` 结果帧可按 ID 输出变化后的尺寸。长度 adder 模块已经让数值运行器实际分裂菌体、生成新 ID 和事件；[回放工作区](replay-ui.md)已经按这份结果显示亲代、子代和时间轴。Space 和 Workflow 已支持首版编辑、检查、撤销/重做、不可变运行记录与导出。独立出生与死亡仍只有协议与序列检查。

环境可选有限库存或理想恒浓度储库；空间可选单层薄层或完整 3D。[项目快照](project-schedule.md)现可保存物种目录和全域外部输入日程，物种也可只登记而不参与运行；显式启用两种物质时，浓度与外部物质账互不串用。[项目 `0.2.0`](capsule-geometry.md)可声明初始胶囊尺寸，并检查已知尺寸能否放进薄层。摄取可选最近格点或固定物理作用范围的采样和沉积；已有[基础扩散](no-flux-diffusion.md)和[演示性移动菌体](moving-cells.md)。独立工具能按体积守恒地重划浓度场，但不能迁移一场运行的全部状态。已有格距与时间步诊断，没有经生物场景验证的默认格距。

现在还没有趋化反馈、障碍物、营养耦合的生长、经标定的分裂、耗氧机制、局部环境入口或黏度场。当前的长度增长只是固定速率演示，分裂使用固定长度增量；胶囊间碰撞、完整外形边界和膜材料账尚未实现，详见[膜面积与拥挤生长](membrane-area-and-crowding.md)。扩散只覆盖均匀系数与无通量边界；运动是定时转向、匀速直行和中心点边界反射；输入日程只处理按步边界变化的全域速率。前端运行服务仍是同步请求，没有任务队列、取消和断线恢复。旧版 WebUI 和模型项目只作为迁入参考；它们没有混入这个交付仓库。先前的速度数字只对应当时无扩散、固定菌体的基准场景，不能代表后续完整模型。

[基础扩散](no-flux-diffusion.md)、[演示性移动菌体](moving-cells.md)、[物种目录及输入日程](project-schedule.md)、[初始胶囊尺寸](capsule-geometry.md)、[逐帧几何与演示性生长](growth-frames.md)、[长度 adder 分裂](adder-division.md)和[第一块结果回放](replay-ui.md)已完成。前端编辑与工作区协议在阶段 4b 完成。下面的顺序与[协议扩展计划](protocol-expansion-plan.md)对应：

前端以英文作为默认界面语言，在 Settings 中切换；布局按专业软件工作区组织。旧版 WebUI 用来对照信息结构和操作经验，当前代码不直接复制它。手机竖屏、横屏、平板和桌面分别检查可读性、触控尺寸及面板滚动；浏览器尺寸模拟与实体设备实测分开记录。

当前扩散使用显式给定的系数，没有从黏度推算。介质黏度若要参与计算，按[状态归属说明](state-ownership.md)成为环境参数或场，并由明确的模块决定它如何影响各物种输运或菌体运动。温度目前不在计划中。

物种目录目前保存 ID、浓度单位、初始值和来源，尚没有可导入任意物性参数的通用格式。后续导入现实物质时，属性还需写清物理量、单位、适用介质或条件和来源；只有明确读取该属性的模块才会改变运行结果。登记本身不会触发扩散、反应或耗氧。这项扩展安排在具体科学机制接入之前设计和验证。

运行中更换环境模块、迁移其内部状态，以及运行中重划整场网格，都需要状态映射和可回放规则。这些任务排在运行任务传输与运行状态格式稳定之后；目前创建新运行时可以选择环境模块，独立浓度场可以守恒重划。前端允许用户选择格距，但给出科学上的推荐值还要等具体机制的空间与时间步检查。完整排队事项见[协议扩展计划](protocol-expansion-plan.md)。

趋化反馈的后续工作按[移动时间顺序](moving-cells.md)接入：MCP 使用新位置的浓度与当前摄取通量计算下一段的转向指令；PTS 模块读取已声明的逐菌体摄取通量。需要连续、同段耦合时，先选择并验证子步或耦合方法。障碍物和真实贴壁行为要在菌体尺寸、障碍物几何及碰撞规则明确后加入，当前矩形边界反射不代表它们已经实现。独立出生与死亡、随机或不对称分裂、营养耦合的生长和分裂，都需要各自的机制与状态规则，不由这一版长度 adder 自动给出。
