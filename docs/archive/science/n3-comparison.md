# N3 构造场景：多 seed、时间步与网格比较

日期：2026-10-01。完整图主研究为 **28 个场景 × 8 个 seed = 224 次运行**；每次 8 个细胞、10 s，均到达终点，0 次失败/partial。初始物理库存核对全部一致，运行前后实现源码 hash 相同。每组 64 条细胞轨迹中的同 seed 细胞并非独立重复，下面 SD、SE 均在 **8 个 seed 的组均值**之间计算。

这是一组构造参数的数值研究。A/B/MCP 的参数和初始状态各不相同，应看同模型的对照差值，不能用本表给模型或工程菌性能排名。更全面的功能检查见 [完整 N3 验收](../verification/verification-n3-complete.md)；[机器摘要](verification/n3-comparison.json)含全部场景、均值、SD、SE、配对差和代码指纹。

## 固定条件与可复现性

物理域 200×100×2 µm；初始平均浓度 1 µM；正梯度 .008 µM/µm；扩散率 1 µm²/s。初始线性场随后自由扩散，没有持续钳制梯度。原模板的细胞、速度、turn kernel 和信号初值保留。零梯度保持相同总库存，恒 motor 对照保留感知与营养摄取，只把运动输入冻结为该场景的初始平均 bias。材料网格组保留同一物理源、材料与初始库存。

基线 dt=.1 s、dx=dy=10 µm；单独比较 dt=.2/.05 s 与 dx=dy=5/2.5 µm，薄层厚度不变。正向观察区为 x≥65 µm。drift=初始 cohort 平均 X 位移/请求时长；停留是数值步左端点区域积分；tumble duty 同样按左端点积分。步端点距离给出的速度低估有内部转弯的路径速度。

```powershell
$env:PYTHONDONTWRITEBYTECODE='1'
$env:PYTHONPATH='src'
python -B examples/runtime/compare_chemotaxis.py --output '<Temp>/comparison-full.json' --seeds 8 --duration-s 10 --workers 4
```

## B 启动状态与 MCP 方向诊断

B 模板初始局部浓度 .72 µM，对应摄取 167.441860465 molecule/s。原 EI 去磷酸化比例 .6、Y=mY=4 µM，而该输入的解析平衡为 e=.6260869565、Y=3.8079470199 µM。启动状态确实不在平衡，但这一事实本身尚不足以解释群体差值。公式符号为 J 增大→去磷酸化 EI 增大→CheA 与 CheY-P 降低→适应后的 motor bias/hazard 降低。MCP 的 ligand 能量符号也使 attractant 增大时 activity 降低，再由负反馈恢复。

主研究之后、执行之前指定的追加诊断保留全部生物速率与几何，增加相反梯度、按初始实际可接受通量计算的 B 适应初值，以及 30 s 观察。B 六组和 MCP 三组各 16 seed，共 **144 次完整运行，0 次失败/partial**。初始物理库存均匹配，运行前后实现 hash 一致；独立初末营养当量余额最大残差为 7.4505806e-09 molecule。统计、每个 seed 的 drift 和原始报告指纹见 [诊断机器摘要](verification/n3-transient-diagnostic.json)。

```powershell
$env:PYTHONDONTWRITEBYTECODE='1'
$env:PYTHONPATH='src'
python -B examples/runtime/diagnose_chemotaxis_transients.py --output '<Temp>/diagnostic-full.json' --seeds 16 --duration-s 30 --workers 4
```

方向对比定义为同 seed 的 `(正梯度 drift − 负梯度 drift)/2`。正值表示随梯度方向改变而出现的吸引方向分量，不能直接等同于无边界介质的渐近漂移。以下单位均为 µm/s，SE 和 SD 在 16 个 seed 对比值之间计算。

| 对比 | mean ± SE | seed SD |
| --- | --- | --- |
| B 原始初值：方向对比 | −0.006695 ± 0.021908 | 0.087633 |
| B 适应初值：方向对比 | −0.005467 ± 0.014037 | 0.056149 |
| B 正梯度：适应初值−原始初值 | −0.007633 ± 0.032381 | 0.129522 |
| B 负梯度：适应初值−原始初值 | −0.010089 ± 0.038239 | 0.152955 |
| MCP：方向对比 | +0.036325 ± 0.009883 | 0.039534 |

MCP 在这组追加构造场景中表现出有证据支持的正方向响应。B 的方向对比接近零，相比 seed 变异很小，尚未分辨出明确群体趋化；适应初始化也没有显示明确改善。因此不能把 10 s 的负对照差值解释成反趋化，也不能把启动暂态当成已证实的原因。

另用完整运行图进行 3 s 开环方向检查：两个细胞保持 +X/−X 游动，只把转向 hazard 设为零，保留场、摄取与信号计算。B 的 bias 从共同 .5 分别变成上坡 .493997、下坡 .515333；MCP 从 .451364 分别变成 .421386、.488406。感知到 motor 的方向符号符合吸引响应；这项检查本身不证明群体行为。[检查数值](verification/n3-control-assays.json)与 `test_chemotaxis_scientific_controls.py` 的两项测试保存该证据。

### 弱响应的量级检查

研究之后另作未拟合的线性响应估计，仅用于判断 B 效应是否可能低于当前统计分辨率。假设无边界、均匀二维 run-turn、弱局部梯度，忽略 B 的 .1 s tumble dwell、体素采样、时间分拆与局部耗竭。设平均转向余弦为 c，κ=λ₀(1−c)，则未扰动速度协方差为 `(v²/2) exp(−κt)`。感知链的每个一阶时间常数 τⱼ 引入因子 `1/(1+κτⱼ)`；适应记忆引入 τₘ。稳态平均速度平衡给出近似：

`v_d ≈ −(λmax−λmin) b′(Y₀) Y′steady(C) g v² τₘ / [2λ₀ ∏ⱼ(1+κτⱼ)]`。

B 使用 memory、EI 与 CheY 三个因子；MCP 使用 adaptation 与 CheY 两个因子，其中导数是适应前 ligand→CheY 增益。全部值取自现有参数，没有调整拟合。局部 C=.72 µM、g=.008 µM/µm、v=5 µm/s 时，B 的量级约 **+0.00896 µm/s**，小于当前方向对比 SE .01404 µm/s；MCP 约 **+0.04131 µm/s**。这支持“B 当前构造参数的响应可能很弱”的解释，仍不能证明精确预测或没有效应。公式假设、中间量及推导见 [解析估计](verification/n3-linear-response-estimate.json)。

死亡抽样实际使用严格位于 `(0,1)` 的 `uniform_open`；checkpoint 的范围校验沿用这一约定。

## 安装验收后的数组类型修复与证据版本

最终安装验收发现，canonical JSON 可将 `100.0` 保存为整数 token `100`。恒定表面酶因此可形成整数数组，旧实现对 extensive 输出作浮点权重原位乘法时会触发 NumPy 类型转换错误；即使该步没有分裂，权重为 1 的继承操作也会经过这条路径。修复将原位乘法改成普通乘法，允许结果自动提升为浮点数组。分配公式、权重、生物参数和浮点输入计算不变。copies 在当前模型中是可连续分配的数量近似，未加入整数抽样机制。

368 次研究的原始报告和原源码指纹全部保留，未把它们标作修复后重跑。原 wheel 的科学源码总指纹与研究完全匹配；逐文件检查，修复仅改变 `engine/chemotaxis_runtime.py` 一行。两个版本指纹为：

## 限制

有限域、初始方向与位置相关、最近体素采样、短时启动和少量 seed 都会影响统计。冻结 motor 的对照只匹配初始 bias，不能自动匹配随时间变化的平均翻转率。所有参数仍属构造或来源模型假设；本研究没有实验数据、工程菌参数拟合或长期性能结论。
