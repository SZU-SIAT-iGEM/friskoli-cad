# 移动菌体与时间顺序 · 阶段 3j

本阶段用[可运行行为图](../examples/runtime/moving_uptake.graph.json)让单菌体的中心位置和朝向随时间变化。`motion.periodic_turn` 在指定时间间隔发出绕 Z 轴的转向角，`motion.reflective_run` 在下一段时间开始时转向，随后以固定速度直行。碰到长方体场地的边界时，垂直于该边界的游动方向反向；一次时间步内多次碰壁也会正确折返。薄层只允许 XY 游动，完整 3D 也允许 Z 方向游动。每帧保留原菌体 ID，并更新位置和朝向。

这里的“反弹”是**中心点运动的镜面反射规则**，没有计算动量或施加碰撞力。细菌游动通常处于惯性可忽略的低 Reynolds 数条件，真实贴壁运动还受形状、鞭毛、表面作用和流体影响。这个规则用于先明确场地边界与运动时序，不能当作贴壁生物学模型。[近壁微游动研究](https://authors.library.caltech.edu/records/b0vry-krq46)说明了边界对轨迹的影响。后续虽可在[项目里登记胶囊尺寸](capsule-geometry.md)，此运动规则仍只按中心点反射，尚未计算菌体外形与墙面的碰撞。

## 行为图和状态归属

运动模块持有逐菌体的 `position: cell.vector, um` 与单位方向 `heading: cell.vector, 1`。菌体局部 +X 轴表示前进方向；运动改变方向时，运行器据此更新朝向四元数，并保留原有的绕前进轴旋转。运行器将位置与朝向作为这一对输出的结果，并拒绝同一菌体组出现两个位置来源。采样和沉积模块新增 `2.0.0` 版本，显式接收同一 `position`；原有 `1.0.0` 继续服务固定菌体行为图。摄取模块及其 `uptake_flux: cell.scalar, molecule/s` 输出没有改变，后续 PTS 模块可按物种与单位连接这个通量。共享协议仍为 `0.1.0`，已声明的 `cell.vector` 形状现在有运行器实现。

碰撞求解与转向、摄取计算分别放置。以后可用保持相同位置与朝向输出的运动实现接入障碍物规则；障碍物几何、碰撞法向、胶囊外形的接触规则和相应的边界行为尚未定义。当前 `motion.reflective_run` 明确只表示矩形场地的镜面反射。

## 一个时间步怎样推进

在时刻 `t`，快照包含浓度 `C(t)`、位置 `x(t)`、摄取通量 `J(t)` 和转向指令。下一步使用这些已有结果：

1. 环境用 `C(t)` 计算扩散，并用上一帧按 `x(t)` 沉积的 `J(t)` 扣除摄取量，得到 `C(t+Δt)`；逐菌体累计摄取同时增加 `J(t) × Δt`。
2. 菌体执行时刻 `t` 的转向指令，游到 `x(t+Δt)`，必要时按边界反射。运动和场更新都从时刻 `t` 的状态出发，彼此不读取对方尚未完成的结果。
3. 在新位置读取 `C(t+Δt)`，计算新的 `J(t+Δt)`，并在那里形成供下一步使用的沉积率。定时转向模块也发出下一段运动的指令。

这是一阶显式近似：整段时间的摄取量归于**起点附近**，没有沿运动轨迹积分。菌体在一个时间步内跨越许多格时，应缩短时间步并检查结果随步长的变化。定时转向只在步边界执行；时间步不能大于设定的转向间隔，跨过间隔时转向最多滞后一个时间步。MCP 感知若使用本步末的局部浓度或摄取通量，其决策应供下一段运动使用；若要模拟同一时间段内连续感知、摄取和转向，需要更细的子步或明确的耦合方法。PTS 对摄取通量的作用也须区分“当前帧测得的通量”和“刚完成时间段累计的摄取量”。

在仓库根目录运行：

```powershell
$env:PYTHONPATH='src'
python examples/runtime/moving_cells.py --geometry thin_layer
python examples/runtime/moving_cells.py --geometry volume
```

演示中菌体从右壁附近朝右游动，`t=0.5 s` 已折返，`t=1 s` 产生转向指令，随后向下游动。两种几何均可输出每帧位置、方向、摄取通量、累计摄取和物质账误差。测试另外覆盖跨格时的摄取位置、3D 的 Z 向碰壁、一次步内重复碰壁、ID 连续和失败时间步不提交位置。速度、转向时间和角度都是演示值，尚未标定；尚无移动模块性能基准、障碍物、菌体间碰撞或趋化反馈。
