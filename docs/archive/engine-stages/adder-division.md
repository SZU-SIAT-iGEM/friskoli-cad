# 长度 adder 分裂 · 阶段 3n

这一阶段接上了[演示性伸长](growth-frames.md)之后的第一次实际分裂。`division.length_adder@1.0.0` 读取同组几何模块输出的胶囊总长。每个菌体从初始长度或上次分裂后的长度开始，累计新增长度；达到组参数 `added_length_um` 时，在**当前时间步结束**发生一次分裂。亲代保留 ID，新子代获得从未使用的新 ID，`0.2.0` 结果帧同时带 `division` 事件和两者的完整状态。模块使用固定长度增量，参数仅为演示值。

这里采用的是**长度 adder**。相关单菌体实验以出生到分裂的新增尺寸描述 adder 行为，见 [Campos 等，*Cell* 2014](https://doi.org/10.1016/j.cell.2014.11.022) 和 [Taheri-Araghi 等，*Current Biology* 2015](https://doi.org/10.1016/j.cub.2014.12.009)。当前实现把胶囊总长作为尺寸指标，适合先与固定直径的伸长模块连接；这些论文不为示例的增长率、阈值或所有菌株提供标定。

## 几何与时间规则

分裂前仍用原来的生长与环境模块执行整个 `[t, t+Δt)` 时间段。若末端长度达到阈值，就在 `t+Δt` 分裂；不推算时间步内部的精确分裂时刻。一个菌体每步最多分裂一次，过大的时间步会使阈值被跨过较多，使用者需要自行检查时间步收敛。

两个子菌沿原胶囊长轴对称排列，朝向与直径继承亲代。为使分裂瞬间的**几何体积**相等且总和不变，胶囊体积取 `V = π(d/2)² × (L − d/3)`，两个子菌各取 `L_child = (L_parent + d/3)/2`，中心距为 `L_child`。这条几何规则不是生物量守恒模型：生长模块尚未从营养摄取计算生物量。若计算出的子菌总长小于直径，或子菌中心落到场地外，整个时间步报错并保留原状态。薄层的 Z 向容纳检查也会重新执行。

目前没有菌体间碰撞、分裂隔膜过程、不对称分配、染色体复制或成熟时间。场地边界对运动仍按中心点处理；两个新胶囊与其他菌体可能重叠。等体积产生新胶囊端面时还会增加几何面积，现阶段没有膜材料账；计算与后续安排见[膜面积与拥挤生长](../design/membrane-area-and-crowding.md)。没有随机波动，也不声称所有菌株都遵循相同的长度 adder。

## 状态如何传给子菌

运行器按每个模块声明的 `on_division` 规则处理逐菌体状态：`copy` 两份相同，`split` 各取一半，`reset` 两份归零。环境场与全局状态使用 `not_applicable`，分裂时不复制。当前 adder 的出生后新增长度归零；摄取模块的累计摄取量平分，保留两者的总和；运动模块的朝向和转向计时继承，位置改为两个新中心。

分裂后，参与图计算的模块在同一时间边界重新计算供下一步使用的输出，不额外推进时间或状态。这样新菌体的浓度采样、摄取通量和沉积率具有正确的数组长度，下一步的环境与摄取物质账仍一致。表示**刚完成时间段**的外部输入通量和储库补给通量保持原值。自定义模块若要参与含分裂的图，必须提供 `refresh(world, node, inputs, state, previous_outputs) -> ModuleResult`：按新菌体数组长度返回输出，同时原样返回状态；缺失或修改状态时运行器报错。这一接口要求只在图中启用分裂时生效。

在仓库根目录运行：

```powershell
$env:PYTHONPATH='src'
python examples/runtime/run_adder_division.py
```

[完整项目](../examples/runtime/adder_division.project.json)从一个长 `2.0 µm`、直径 `0.8 µm` 的菌体出发，以 `0.5 µm/s` 演示性伸长，出生后增加 `1.0 µm` 时分裂。`0.5 s` 一步，第 `2.0 s` 的帧会出现两个各长约 `1.633333 µm` 的菌体，新增长度都重置为零。项目只登记氧，没有氧计算节点。[测试](../tests/test_division.py)覆盖重复分裂、不同出生长度、薄层与 3D、状态继承、摄取物质账、环境输入边界和失败回滚。
