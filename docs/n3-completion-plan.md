## 科学与交互约定

PTS 示例的实体底物释放产物、引诱物源和摄入养分引用同一物种及库存。MCP 示例的无限均匀营养背景是明确的实验假设，与独立引诱物梯度分开登记；不将该设置写成 MCP 的普遍生物学定义。浓度始终非负，响应方向由感知机制决定。

来源 A/B 的记忆、生长、传质与运动假设分别显示。简化模型的请求通量驱动信号、总 copies 的重复稀释、资源限制制造死亡等已知错误不迁入；修订采用接受摄取、真实 turnover 和显式资源诊断。论文支持的机制方向与具体参数是否标定分开记录。

界面保留专业软件的紧凑工作区，新增能力通过目录、模板、可读参数证据和结果图表进入。浏览器尺寸模拟、手势逻辑和实体设备实测分别记录，不把自动化检查总数当作科学有效性或实际设备体验的证明。
