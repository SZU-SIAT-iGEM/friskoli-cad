# 尚未完成的计划与验收清单

更新：2026-10-03。本页只列当前仍未完成的实现或验收；本轮 A03、S01–S10、M01–M11、U01–U12 的逐项实际交付与支持范围移至[实施记录](implementation-2026-10-03.md)，不再把已有模块、包管理、暂停续算、离线编辑列成未实现。完整责任划分见[系统运行图](system-execution.md)。

## 6. 已实现项与更新规则

本轮统一模块接口、类型/owner/诊断、73模块、包管理、任务恢复和工作区实现见[逐项交付表](implementation-2026-10-03.md)。早期模块、N1–N4、M4、标准子集和Wiki的历史验收继续保留，不追溯改写旧记录。

三池输运、温度/PCR模拟、不经定义的负浓度排斥及为展示强制生命周期均不加入当前要求。复杂自由停靠、桌面壳、通用CFD、自动序列设计、在线社区和分布式GPU仍按实际需要评估。

`contrib/repro-cli`、`contrib/plugin-sdk` 继续只审阅、不合并。安装器按发布需要构建，不因常规源码或文档变动反复打包。每次更新本页只移除有实现和证据支持的缺项；验收未做就保持“待验收”。
