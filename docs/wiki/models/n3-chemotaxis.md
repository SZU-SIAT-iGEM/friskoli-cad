# N3：把感知、营养和运动放在同一个场景中

本页解释 CAD 的 `chemotaxis-spatial-v1`。A、B 两套来源模型经过拆分，可以比较不同适应方式；另有采用经典 MWC 结构的 MCP 受体模型。它们保留不同的生物假设，尚未经过本项目工程菌实验标定。公式、来源位置与数值差异见 [科学说明](../../archive/science/n3-mechanisms.md)，实际验证结果见 [验证记录](../../archive/verification/verification-n3-complete.md)。

## 三种感知方式

| 方式 | 记住什么 | 持续刺激后怎样变化 |
| --- | --- | --- |
| A 浓度记忆 | 最近的胞外糖浓度 | 时间差逐渐消失，回到 PTS 本身的 motor bias |
| B CheY-P 记忆 | 最近的细胞内 CheY-P | 有效 motor 信号回到设定基线 |
| MCP 受体适应 | 连续平均甲基化状态 | 受体 activity 回到设定适应水平 |

A、B 都允许真实营养摄取驱动 PTS。关闭趋化信号的对照仍然可以摄取营养，这样才能区分感知带来的运动变化和营养带来的生长变化。

MCP 用 MWC 自由能把 ligand 结合与甲基化状态连起来，再用 activity 负反馈更新甲基化。这里使用简化的线性反馈，没有显式 CheR/CheB 和有限甲基化位点。ligand 与营养可作为独立物种：前者被感知，后者被摄取。均匀营养背景由外部持续补给，补给量进入账本；这是一种对照场景。

## 从信号到运动

motor bias 决定 run 转为 tumble 的危险率。瞬时转向与固定时长 tumble 分开选择；后者停留时不游动。A、B 的原转角规则与均匀随机方向是不同的机制选项。

运动保存剩余累计 hazard，信号变化时继续使用这只时钟。一个积分区间可以出现多次事件，输出帧不会重新抽方向或时钟。空间阻挡会限制位移，但事件时间继续推进。模型没有计算鞭毛、流体或接触力。

## 接触释放与营养生长

细胞接触可降解材料后，用其表面有效酶提出水解请求。相同细胞接触多个材料时共享酶预算；材料耗尽、无酶或没有接触时停止产物释放。产物直接进入同一个胞外浓度场，随后扩散并由附近细胞竞争摄取。

当前方案不使用 A 原来的 contact/surface/bulk 三池。原 A 页保留的是来源解释，其局部传质假设已被替换，不能直接当作 CAD 当前运行说明。

所有释放产物进入同一个场，释放速率、扩散和有限摄取共同决定局部堆积，没有另外规定多少糖给细胞、多少糖留下维持梯度。一个无初始糖、无预置梯度、静止接触菌的 2 秒构造检查中，较慢扩散产生了更高局部峰，较快扩散让峰更平；摄取和余量都来自同一份物质账。定量结果与适用范围见科学说明。

只有实际摄取的糖进入胞内可用库存。A 的增长需求还受胞内 Monod 关系影响，B 使用产率和最大增长率限制；两者都不能花掉不存在的底物。空间放不下增长后的细胞时，该份营养保留。

## 表达、死亡与分裂

INP 状态表示总拷贝数。体积变大使浓度下降，总数量不会凭空减少。合成与 turnover 改变数量，真实分裂再分配一次。A 表达受 health、实际增长率及膜占用反馈，B 保留简化表达。

health 是经验模型状态。A 使用膜占用与超额表达成本；B 使用相对基础表达的负担，它可以大于 1。这些规则会影响模拟中的死亡与表达，不能直接解释为测量得到的健康百分比或最优表达量。

固定半径球柱体增长到面积 adder 阈值后提出分裂。两个子代必须满足最小几何尺寸且放置不重叠；受阻时延后。体积、胞内糖和总 INP 分配守恒。新细胞极会增加几何面积，目前未建立独立膜材料库存。

## 怎样读运行结果

沿梯度位移、接触停留和生长量应分别观察。仅仅停得更久，不能说明趋化增强；仅仅轨迹更密，也不能说明摄取更多。需要零梯度、关闭信号和驻留对照，再比较多个 seed 以及时间步、网格变化。

当前已完成 224 次主比较和 144 次追加诊断，均到达终点，没有失败运行。10 秒主比较中，A 相对恒 motor 对照的 drift 配对增量为 +.683±.145 µm/s（mean±SE）；B、MCP 的短时结果没有同时给出明确增益。追加 30 秒、16 seed 的正反梯度诊断中，MCP 的方向分量为 +.0363±.0099 µm/s，支持该构造场景下的正向响应；B 在适应初始化后为 −.0055±.0140 µm/s，尚未分辨出明确群体趋化。

B 的开环检查确认上坡时 motor bias 降低、下坡时升高，但群体效应较弱；未拟合的解析量级估计约 .009 µm/s，低于这组诊断的标准误。不能据此断言没有趋化，也不能把先前负差值解释成反趋化或已证实的启动问题。A 仍有可见时间步敏感性。所有结果和局限见 [多 seed 与网格研究](../../archive/science/n3-comparison.md)，这些构造参数不支持工程菌性能排名。

库存记录是 cellobiose-equivalent 的转移账，包括固体、胞外、胞内、生长消耗、死亡移出与外部补给。它没有完整表示碳元素、ATP 或蛋白合成费用。源码对照和构造测试能验证数学与程序性质，工程菌性能仍需实验数据。
