# 无扩散摄取循环 · 阶段 3b

这一阶段把[行为图编译器](engine-compiler.md)接到了数值运行器。浓度是环境模块持有的场状态。本例只用菌体摄取改变浓度；后续已接入独立的[基础扩散模块](no-flux-diffusion.md)。

```text
环境浓度 C(t) → 采样到每个菌体 → 摄取通量 J(t) → 汇总到网格
      ↑                                            │
      └───────── 下一步按 J(t) 更新 C(t+Δt) ──────┘
```

行为图中的回边标为 `previous_step`。在 `t=0`，环境给出初始浓度，菌体计算初始摄取通量；从第一步起，环境用上一步的通量推进浓度。这是显式时间步。每个菌体保留 ID、位置、朝向、通量和累计摄取，运行器每步生成一帧；环境场快照同时标明物种、单位和格点几何。浓度变化表现为相邻快照的差，离散事件列表留给出生、分裂和死亡，本例中为空。另一种实际可运行的环境实现见[环境模块对照](environment-swap.md)。

## 数值含义

- 网格可选择单层薄腔或完整 3D；菌体中心落在哪个体素，就读取哪里的浓度。薄腔会对 Z 方向使用同一个浓度值；菌体位置在本例中固定。几何选择见[空间尺度](spatial-resolution.md)。
- `1 uM` 在 `1 µm³` 中约有 `602.214076` 个分子。体素体积为 `dx × dy × dz`；把同一体素内各菌体的 `molecule/s` 通量相加，再除以体素体积与换算系数，得到环境的 `uM/s` 消耗率。
- 例子的摄取律是 `J = kC`，只用于检验模块连接与守恒。`k = 100 molecule/(s·uM)` 是演示参数，没有经过生物实验标定。
- 每一步按 `C(t+Δt) = C(t) − Δt × consumption_rate(t)` 更新。菌体累计摄取按同一个 `J(t) × Δt` 增加，因此二者的分子数变化应相等。若某个体素会变成负浓度，该步报错且不推进时间。

运行示例（在仓库根目录）：

```powershell
$env:PYTHONPATH='src'
python examples/runtime/run_demo.py
python examples/runtime/run_demo.py --geometry volume
```

薄层示例从 `10 uM` 开始，两个菌体各自位于一个 `5 × 5 × 1 µm³` 体素。第一秒各摄取 `1000` 个分子，相应体素降到约 `9.93358 uM`；其他体素保持 `10 uM`。完整 3D 示例将两个菌体放在同一 XY 位置的不同高度，体素为 `5 × 5 × 5 µm³`，第一秒各自所在体素降到约 `9.98672 uM`。程序逐行输出时间、菌体所在体素的浓度、累计摄取及全场物质量误差。

## 性能观察

这个例子每步的场更新和菌体汇总使用 NumPy 数组，计算量大致随菌体数与体素数之和增长。结果帧仍需逐菌体生成，因此整体速度不能只看数值公式。

阶段 3b 最初在当前开发机测得：薄层 `128 × 128 × 1` 个体素、每次推进 `0.1 s`、连续测 3 步，10000 个菌体约 `0.050–0.053 s/步`。加入完整 3D 后的对照和尺度限制见[空间尺度说明](spatial-resolution.md)。新基准脚本会进行多组测量并报告中位数：

```powershell
$env:PYTHONPATH='src'
python examples/runtime/benchmark.py --cells 10000 --steps 3
python examples/runtime/benchmark.py --geometry volume --cells 10000 --steps 3
```

测试计入模块计算、结果帧生成和逐帧身份/时间检查，不计入初始化、外部数据的完整 JSON Schema 检查、磁盘写入和浏览器绘制。外部帧输入仍执行完整协议检查；运行器自己生成的帧已由有类型数组与经过校验的元数据构造，每步只做增量检查。最初对每一帧重新执行完整 JSON Schema 检查时，10000 个菌体约需 `2.05 s/步`；瓶颈主要在验证器，不在浓度计算。这些数字只描述当前无扩散示例，不能推断之后接入运动、扩散或更多模块的速度。

## 本例边界

运行器支持 `field.scalar`、`cell.scalar` 和用于移动的 `cell.vector` 数值执行，薄层与完整 3D 均可运行；本例仍只有一个菌体组、一个均匀初始浓度的物种和固定菌体位置。本例的场没有扩散；扩散版行为图见[无通量扩散](no-flux-diffusion.md)，移动版见[移动菌体](moving-cells.md)，分裂版见[长度 adder](adder-division.md)。当前空间耦合按最近体素采样；旧固定物理作用范围方案见[归档说明](archive/legacy-runtime/box-support.md)。本例保留阶段 3b 的语义；后续[科学 profile](archive/legacy-protocols/chemotaxis-profile.md)已单独实现胶囊碰撞、营养生长、死亡与分裂，并接入前端回放。协议可以表达比各个运行器更多的形状与事件；未实现的形状会明确报错。两种基础环境实现通过同一套菌体模块运行，限制见[环境模块对照](environment-swap.md)。
