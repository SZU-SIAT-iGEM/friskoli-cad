# 固定菌体的基础扩散 · 阶段 3i

这一步在已有菌体摄取图上增加了可替换的 `field.diffusion_no_flux` 模块。它按每个相邻格面两侧的浓度差计算传递率：一格增加多少，另一格就减少多少；场地边界没有向外的通量。薄层只在 XY 方向传递，完整 3D 在 XYZ 方向传递。扩散系数 `diffusivity` 的单位是 `um2/s`，由具体物种的模块实例提供。示例用 `5 um2/s`，尚未标定。

浓度状态由 `field.local_inventory` 的 `2.0.0` 版本持有。它在原有的摄取率之外，还接收扩散率，并按 `C(t+Δt) = C(t) + Δt × (扩散率 − 摄取率)` 前进一步。原来的 `1.0.0` 版本仍在登记表中，旧行为图无需修改；令新图的扩散系数为 `0` 时，薄层与 3D 的运行结果都与旧版摄取图一致。共享协议仍为 `0.1.0`，本次变化只新增模块并增加了一个模块版本。

## 时间与稳定性

新图中，扩散模块从 `previous_step` 读取 `C(t)`，在本步计算扩散率；浓度模块同时读取该扩散率和上一步已汇总的摄取率，得到 `C(t+Δt)`，然后菌体读取更新后的浓度。结果快照里的 `diffusion_rate` 是刚刚完成的时间步所用的率；初始帧尚未推进，所以为零。

当前使用显式 Euler。若某个轴只有一格，该轴不参与扩散；其余轴的上限为：

```text
Δt ≤ 1 / [2 D × Σ(1 / 格距²)]
```

运行器会拒绝超过此上限的步长，保持上一步状态。即使满足扩散条件，菌体摄取过多仍可能造成负浓度，该步也会被拒绝。这个检查只适用于当前**均匀扩散系数、均匀直角网格、无通量边界、显式方法**；换方法后应由对应模块声明自己的限制。

在仓库根目录运行：

```powershell
$env:PYTHONPATH='src'
python examples/runtime/compare_diffusion.py --geometry thin_layer
python examples/runtime/compare_diffusion.py --geometry volume
```

对照在固定菌体、初始均匀 `10 uM`、运行 `1.5 s` 的场景里比较扩散系数 `0` 与 `5 um2/s`。薄层中心格浓度由约 `9.90078` 变为 `9.93682 uM`，相邻格由 `10` 变为 `9.99214 uM`；3D 中心格由约 `9.98009` 变为 `9.98974 uM`。全场损失与菌体累计摄取相符，误差为浮点舍入量级。测试另用非均匀脉冲检查 XY 和 Z 方向的格面传递、总量守恒与稳定步长。

当前扩散图使用有限库存环境的 `2.0.0` 版本；理想恒浓度储库仍按原有规则运行，没有接收扩散率。当前行为图的初始浓度仍是均匀标量；非均匀初始场还没有进入项目格式。尚无菌体移动、变动黏度、空间变化的扩散系数或其他边界模型，也没有新扩散模块的性能基准。协议目录里的 `field.diffusion` 是早期的连接示例；本次可执行模块使用明确的 `field.diffusion_no_flux` 名称。
