# PTS 摄取与甲基化适应

当前 A/B 共用 `signal.pts_methylation@1.0.0`。局部糖浓度先生成摄取请求，经共享库存结算后的实际通量驱动 EI；甲基化反馈调节感知复合体活性，再推进 CheY-P 和马达读出。模块没有浓度输入。

A/B 的容量公式分别为膜面积占用限制和参考面积缩放，其余信号与马达参数相同。甲基化是有上下限的连续状态；饱和时可以适应不完全。MCP–MeAsp 保留独立的配体结合模型。

完整方程、初态、数值方法及参数见[第一版科学说明](../first-release/science.md)。通路依据为 [Neumann 等，2012](https://doi.org/10.1073/pnas.1205307109)，具体能量关系与动力学参数仍需实验约束。

`tests/test_pts_science.py` 检查容量、摄取和来源记录；`tests/test_pts_methylation.py` 检查关闭摄取、阶跃与撤除、冻结适应、甲基化边界、独立 RK4 对照、步长收敛、参数范围及状态恢复。
