# M4：有限胶囊碰撞参考实现

`engine/collision.py` 提供几何间隙与运动安全检查。全部长度使用 µm，heading 无量纲；运动区间用归一化时间 `t ∈ [0,1]`。这些合成几何测试不代表任何生物参数测量。

本模块采用保守的运动规则：整个提议轨迹通过检查才接受；否则保持该区间开始时的位置、朝向和尺寸。它不计算接触力、摩擦、流体作用、碰撞反弹或真实拥挤运动，也不替换旧的 center-point `reflect_in_box`。

## 几何与最小间隙

`Capsule(cell_id, position_um, heading, length_um, diameter_um)` 中 `length_um=L` 是胶囊总长，`diameter_um=d` 是总直径，要求 `L≥d>0`。中心为 `p`，单位方向为 `h`，半径 `r=d/2`，中轴线段半长 `a=(L-d)/2`；胶囊是线段 `[p-ah,p+ah]` 与半径 `r` 的球的 Minkowski 和。heading 仅接受在 `1e-10` 内为单位长度的输入，并消除该范围内的浮点长度误差。`L=d` 自动得到球。

三个静态函数：

- `capsule_gap(A,B)`：有限中轴线段的最短欧氏距离减去两半径。计算覆盖二次函数的所有边界最小值和内部驻点；平行、反向、点线段均有定义。正值为表面间距，零为接触，负值表明重叠。
- `capsule_box_gap(C, BoxObstacle(id, lower_um, upper_um))`：有限线段到闭合轴对齐长方体的最短欧氏距离减去半径。按线段穿过六个面所在平面的参数分段，每段的点到盒体距离平方为二次函数，检查区间端点和受限驻点。边角距离使用欧氏距离。负值是重叠指标；线段进入盒体时返回 `-r`，不能作为真实穿透深度使用。
- `capsule_wall_gap(C, extent_um)`：胶囊对 `[0,extent_x]×[0,extent_y]×[0,extent_z]` 的六个内壁间隙最小值。胶囊在各轴的包围范围由两个线段端点加半径得到。

上述“准确”指几何形式精确求最小值，实际计算使用 binary64，不能理解为任意精度或严格区间算术。

`geometry='thin_layer'` 和 `'volume'` 使用同一套三维距离。薄层仍有实际 Z 厚度，越出上下壁的胶囊会被诊断；这里没有压扁胞体、忽略 Z 或替调用方约束运动方向。

## 连续轨迹与覆盖证明

`guard_motion(start, end, *, extent_um, obstacles=(), geometry='volume', tolerance_um=1e-9, max_subdivisions=256)` 要求 start/end 具有相同且唯一的稳定 ID，包含所有相关细胞，包括不移动者。end 可以按不同顺序提供；结果 `capsules` 保持 start 的顺序。尺寸在这次运动内不能变化。

中心位置线性插值；heading 沿最短球面圆弧、匀角速率插值。严格反向时采用确定性的正交方向：选与原 heading 最不平行的坐标轴，去除其平行分量并归一化。近反向处的浮点分支也采用该方向，误差处于下述容差范围。这一规则指定了中间姿态；调用方如需要“先旋转、后平移”，应明确提供两个运动区间。

设两端中心位移为 `Δp`，heading 转角为 `θ∈[0,π]`。同一胶囊任何点在归一化时间上的速度上界为

`v_bound = ||Δp|| + a θ`。

因此胶囊到固定盒体/内壁的间隙函数是 `v_bound`-Lipschitz；两个运动胶囊间隙的 Lipschitz 常数不超过两个上界之和。对于一个时间区间 `[l,r]`，中点 `m` 的间隙 `g(m)` 给出全区间下界

`g(t) ≥ g(m) - v_bound (r-l)/2`。

只有这个下界至少为 `tolerance_um` 时才接受该区间；否则继续二分。发现低于 `-tolerance_um` 的间隙时报告 `collision`。这覆盖完整区间，可以拦截端点合法的高速越障、两个细胞交换位置以及旋转扫过障碍物；它没有用离散采样无碰撞来代替连续安全证明。

几何不随时间变化的约束直接检查一次，允许静态相切。运动中的相切、贴壁滑动、非常接近障碍物的安全轨迹可能无法在有限预算内证明，因而被拒绝。这个保守性是已知限制，不应解读为实际粘附或停滞机制。

## 预算、数值容差与初始诊断

`max_subdivisions` 名称沿用 API，但实际含义是**每个约束、每次群体重验最多进行的中点间隙评估次数**，默认 256，不是递归深度。`GuardResult.evaluations` 汇报总评估次数。预算不足报告 `budget_exhausted`；浮点间隔无法继续分割或遇到不可用数值报告 `numerically_uncertain`。两种情况均作为普通 blocked 返回，不表示科学死亡或求解器致命故障。

默认绝对容差为 `1e-9 µm`，它是数值参数，不是生物学接触距离。初态低于 `-tolerance_um` 的间隙抛出 `InitialOverlapError`，其 `.contacts` 提供涉及的细胞 ID、类型和目标 ID；不会随机推开细胞或缩小尺寸。初态在 `[-tolerance_um,0]` 范围内按数值接触带处理。移动路径要求额外的正容差余量。

guard 要求 `tolerance_um ≥ 128 ε S`，其中 `ε` 为 binary64 machine epsilon，`S` 是至少为 1 的全场最大坐标、域尺寸或胶囊总长；不满足时明确拒绝该配置。这个检查为通常坐标运算留出误差余量，但不是经过形式验证的浮点误差证明，也不能替代对极端尺度或病态输入的审查。静态间隙函数返回原始 binary64 结果，不自动截零。

## 同时运动与顺序

每一轮都根据同一组运动提议检查所有约束。若两个移动者之间有碰撞或无法证明安全，二者共同 blocked。该轮完成后同时固定所有新 blocked 细胞，再重新检查其余移动者与固定者，直至没有新增阻挡。因此被固定的前方细胞不会让后方细胞继续穿过它原本的位置。

阻挡集合单调增长，最多经过细胞数次有变化的轮次。内部按 ID 排序，约束和诊断均采用稳定顺序，输入排列不会改变按 ID 的结果。该方法是小规模、全对全参考实现，没有声称可高效处理大型高密度群体。

`Contact` 含 `cell_ids`、`kind`（`cell`、`wall`、`obstacle`）、`target_id`、`reason`。`GuardResult` 含最终 `capsules`、稳定顺序的 `blocked_ids`、`contacts` 和 `evaluations`。初始非法布局与一般运动阻挡是两个不同的调用结果。

## 已执行验证

`tests/test_collision.py` 覆盖解析球/胶囊间隙、有限轴端点、平行和反向轴、近乎平行轴、交叉轴、盒体面/边/角、线段内部最近点、空群、相切、薄层真实厚度、初态非法、合法移动、越壁、越过薄障碍、pair swap、非中点碰撞、旋转扫掠、反向旋转、球极限、冻结后的二次检查、ID 排列不变和有限预算耗尽。采用构造的解析基准与可检查的运动结果，没有将仿真画面当成碰撞正确性的证据。

本模块的距离推导和 Lipschitz 推导均如上给出，不复制外部来源模型的完整动力学或生物参数。
