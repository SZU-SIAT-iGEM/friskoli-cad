## 本轮完成的运行规则

1. 同步运行先检查总时长有限性、场数据、细胞和结果预算，再构造/推进模型；增长过程中继续检查实际累计输出。capabilities 公布相应限制。前端按匹配的任务能力、顶层同步能力、旧服务兼容值依次读取步数。
2. 新增 `POST /api/runs/preflight`，与正式提交共用完整 Submission 校验和资源估算。Checks、Run 与 seed 批次使用相同入口；失败不创建本地任务、不占用幂等键、不自动重试或改变科学输入。
3. 修复合法异步细网格被同步 viewer 的 4096 XY 格上限误拒。100×100×1 MCP、1900 步、每 10 步保存一帧的 HTTP 检查通过，预计输出 125518706 bytes。
4. 生命周期示例 1900 步、每步保存时预计约 1104.81 MiB，超过 128 MiB。检查会提前指出输出预算并建议手动将保存间隔设为至少 9；执行 dt/steps 不变。单帧过大单独说明，提高保存间隔无法解决。
5. 首次真实 PTS-A 1900 步在原默认 60 秒时限下仅提交 397 步，状态 failed/partial，保留 398 帧。并发回归测试会影响运行速度，此记录不能推断空闲机器性能。
6. 本地 CLI 增加 `--task-wall-time-s`，默认 1800 秒；运行检查明确显示实际服务时限。嵌入式 `TaskLimits()` 的 60 秒默认值保留。没有修改 worker 发布顺序、科学模型、dt、网格或输出采样来使验证通过。

## 本轮完成的交互

- 菌群列表选择立即更新工具按钮；锁定、隐藏、无适配器和 Results 状态不能由快捷键绕过限制。
- 障碍盒和底物盒可移动/缩放。预览按每轴真实格距对齐、最小一格、限制在域内；参数写回同一个注册 graph 节点，碰撞与非法参数不会留下部分编辑。
- 来源球可移动与等比缩放；释放范围仍可在场地边界裁剪。薄层保持 Z 位置与盒厚度。当前协议的轴对齐盒和球均不提供旋转。
- 三维变换沿用项目事务、Undo/Redo 和结果失效规则。不会把旧前端任意 mesh、装饰性信号球或放大的菌体当作当前科学对象。
- 测量优先命中真实可见对象/菌体表面，不使用菌群代理块或未知几何占位球。显示 A/B 世界坐标、对象或菌体 ID、距离与三轴差值；空白处显示参考平面来源。Results 保持只读。
- Workflow 中 F 使用图的 fit；Ctrl/Meta/Alt/Shift 组合与输入编辑不触发单键空间工具。
- 日志/检查面板可从顶沿拖动、键盘调整、双击恢复并保存高度；短窗口为视口保留空间。Export 移到顶部 Open/Save 所在文件操作区。
