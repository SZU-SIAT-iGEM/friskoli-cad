# 环境变化日程：已实现部分与后续安排

第一版已在[项目物种目录与输入日程](project-schedule.md)中实现：项目快照保存物种初始浓度、全域外部输入速率、时间变化点、来源和可选重复周期。运行器只在时间步边界施加变化，并逐物种记录外部净输入。使用同一项目快照可以重复运行。PCR 的时间程序仍只作为日程形式的类比；温度目前不在开发计划中。

`oxygen` 可以只登记而不进入运行计算；需要时才接入自己的浓度场和日程。登记名称不自动产生恒定浓度、耗氧、输运或气液交换机制；这些机制需要独立模块与科学依据。介质黏度属于环境属性，不登记成化学物种。其状态归属见[状态归属说明](state-ownership.md)。

后续仍需分别处理局部入口、瞬时投料、非均匀初始场，以及更复杂的浓度维持规则。运行中更换环境模块还要定义旧状态怎样映射到新模块，不能由输入日程自动代替。MCP/PTS 与移动菌体的连续耦合时序另见[移动菌体说明](moving-cells.md)。
