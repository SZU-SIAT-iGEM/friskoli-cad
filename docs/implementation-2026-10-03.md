# 系统机制与模块扩展实施计划

开始：2026-10-03。基线：`18d250e`，分支 `feat/n4-design`。本轮按用户要求实施 A03、S01–S10、M01–M11、U01–U12；本页先定义完成后的语义与验收条件，再记录真实实施进展。本文中的目标不代表已实现。

## 一、最终形式与兼容规则

产品仅采用两类可执行形式：**系统机制**和**注册模块**。系统机制负责数据类型、调度、设备、状态事务、几何约束、资源限制、文件和命令；基础模块与特殊科学模块通过同一执行接口提交计算结果。模板、参数包、向导只是对象和模块的可编辑组合，不保存隐藏科学算法，也不按案例 ID 选择执行路径。

旧 profile、旧输入版本和旧结果的解释保留。扩展采用新的 `modular-spatial-v1` profile / Project 0.6、模块合同 0.2 与独立执行声明；Task 0.6、Workspace 0.7、Design 0.3 承载长时运行和新编辑状态。读取旧格式时明确报告兼容方式，不默默启用新的生物机制。某能力只有声明和 UI、没有真正进入计算或恢复链时，仍标为未完成。

新执行声明包含阶段、状态 owner、可读范围、可提交 effect、参数/端口语义、设备实现、初始化/分裂/死亡/迁移规则和证据。模块读取只读 StepContext，返回 outputs、自己的 state 和 effects；系统检查和合并后一次提交。模块不能直接修改共享场、细胞身份或其他模块状态。显式安装的 Python 插件属于受信任代码，受控接口不冒充操作系统安全沙箱。

端口明确 shape、dtype、quantity、unit、entity set/顺序、坐标/轴序、采样位置、domain/grid revision 与时间角色。转换、广播、映射、重索引和聚合必须是可见模块；相同数组长度不能代替身份匹配。系统保留原始声明与最终编译合同，结果可追溯。

## 二、任务、长时计算与数据

| 范围 | 完成后的语义 | 必须验证 |
| --- | --- | --- |
| S01/S03 | 统一模块接口与系统提交，内置和安装模块均按注册声明执行；简单增长也接受相同几何准入 | 外部示例模块实际改变结果；未授权写入/owner 冲突提前拒绝；失败恢复全部状态与 RNG |
| S02 | 包预览只读清单，安装独立进行；依赖解析产生精确版本/hash lock，参数/模板数据与执行代码分离 | 相同版本内容冲突、依赖环、缺依赖、坏 hash、路径越界、卸载引用保护；新进程按锁执行 |
| S04/S05 | 编译汇总独立检查，标识 pass/fail/unknown/not_applicable/skipped；修复为系统 command | 多项独立错误同时显示；前置缺值不产生大量衍生错误；旧 API 可返回兼容首错误 |
| S06 | 全图 planner 按模块实现和依赖选择 CPU/CUDA，记录求解组、数据驻留、转移与内存 | 不支持设备提前拒绝；无隐式降精度/降网格；CPU 参照一致性与真实分派 |
| S07 | 用户选择物理时长或步数，dt 独立；12 h=43200 s，dt=.01 时432万步。新任务与设计合同、能力上限、输出建议和导入导出同步升级 | 精确步数/末时刻、不整除时长显式提示；边界值、旧格式限制；足额长时数值运行和有界输出 |
| S08 | 暂停在已提交步形成持久 checkpoint；恢复创建关联的新运行段，保留原运行及结果。下载和导入状态显式进行 | 连续/恢复对照；worker/服务中断；大场二进制 checkpoint；取消/完成/暂停竞争；UI 与状态一致 |
| S09 | 环境/网格变化先预演映射，再从已保存边界创建新段；同域守恒重划和改变域分别处理 | 库存、单位、日程、ID/RNG、模块状态完整；无映射拒绝；变更失败原状态可继续使用 |
| S10 | 新帧含数组描述符：little-endian dtype、shape/轴序、单位、domain revision、字节数/hash；数组独立传输。浏览器按帧/块按需获取和有界缓存 | 拒绝大小/hash/shape 不符；慢传输不无限积压；浏览任意帧、事件与导出保持完整；旧 JSON 可读 |

12 h 支持不能通过增加 dt、提高壁钟限额或减少科学计算获得。资源预检覆盖场/工作缓冲、细胞增长、事件、checkpoint、输出、浏览器解码；运行中保持实际限额。用户自行验壁钟加速，工程验证只报告正确性、实际运行范围和资源边界，不承诺未经实验验证的12小时生物预测。

任务恢复与环境变更是系统机制。新运行段保存 parent run、起始步/时间、目标终点、checkpoint hash 和变更记录；旧段不可改写。场预览只影响输出，完整计算格距独立保存。

## 三、模块库与科学语义

| 范围 | 模块和系统行为 | 科学/数值边界 |
| --- | --- | --- |
| M01 | 注册单位转换、标量广播、实体映射/聚合、delay、lowpass、持续阈值、胶囊几何和简单增长 | 初值、时间角色与实体索引明确；previous-step 不冒充任意延迟 |
| M02 | 初始数组、时变局部速率、脉冲、受控浓度边界模块；编辑器使用统一日程表 | t=0 初始化一次，事件有固定边界规则；每物种外部净输入入账，恢复不重放已消费事件 |
| M03 | 条件物性目录与显式黏度作用模块；登记本身不产生计算 | 每属性有单位、适用条件、来源及不确定性；黏度不作化学物种；扩散/运动各自声明响应 |
| M04 | 唯一胞内库存 owner 接收 accepted amount，按明确顺序分配维持与增长 | 摄取只入账一次；生长受阻返还未用量；分裂按声明份额继承 |
| M05 | **按用户调整，不实现膜材料库存。**系统默认分裂几何所需的新膜可获得，记录增加的几何面积；不以膜材料不足阻断分裂 | 不宣称膜物质量守恒，不虚构膜分子；受体/表达拷贝数仍按自身模块继承，不因面积增加自动复制 |
| M06 | 显式氧消耗及气液交换模块，接入独立物种场 | 消耗、外部交换分别记账；无氧限制模块时登记氧不改变生理 |
| M07 | 材料水解化学计量、接触/分泌酶反应提供者，固体到可溶产物通过统一反应结算 | 纤维无水葡萄糖单元＋水→葡萄糖须声明计量与单位；催化剂不按反应物扣除；参数证据不伪装实验标定 |
| M08 | 黏附/脱附、材料侵蚀、接触响应分别注册 | 黏附状态、几何更新与力学假设分开；现象学接触不能称实测力学；受阻不等于死亡 |
| M09 | 残体保留/释放模块接收死亡剩余量，控制碰撞体和向场的释放 | 来源从死亡剩余账转移，不重复生成；耗尽与移除事件可回放 |
| M10 | 有来源外部速度场、守恒 upwind 平流、边界交换、表面/体映射、高阶匹配权重；闭合定向三角网格导入与物理体素化 | CFL 子步、外部净通量、匹配支持与守恒；网格体素化是明示近似，不声称连续三角面接触或 CFD |
| M11 | 转化与谱系观察模块，按计算步记录生命周期关系和产物/底物指标 | 分母、时间窗、缺值、祖代/后代与单位明确；稀疏存帧不丢事件 |

新科学机制必须随注册声明提供公式、来源、适用域、参数证据与正反例。没有真实菌株标定数据时采用明确的构造或来源参数，由可编辑模块表达假设。运行时源、反应、摄取、残体和边界共同经系统结算，不能各自从同一份库存独立扣除。

## 四、工作区最终交互

| 范围 | 完成后的操作形式 | 验证重点 |
| --- | --- | --- |
| A03/U02 | 共享 command 计算 enabled/reason，菜单、右键、触屏与键盘调用同一操作；诊断按路径定位真实控件 | 锁定后所有入口一致；backend/预览格距/output 等不误跳 Steps |
| U01 | 受管理模板保存 owner、生成器/版本与 overrides；复制、删除、替换、升级先列引用变化，再一次应用；允许明确解除托管 | 手工连接保留/冲突可见、ID 重写完整、Undo/保存重开一致、可修复草稿不能误运行 |
| U03/U04 | 放置与重散布先预览、属性确认再提交；初始梯度、有限源、浓度边界使用不同模块向导 | 不静默减菌数；删除时列相关节点/连接；取消无科学副作用 |
| U05 | 参数分必填/参考/待研究，少量必要输入引导；群内分布有 seed、适用范围与来源 | 数值与实际驱动模块绑定；unknown 不当0；不可执行组合提前显示原因 |
| U06/U07 | 目录缓存与本机离线入口、显式重连、最近项目；ViewState 保存相机/选择/展开/阅读位置，独立于科学 hash | 冷启动离线、恢复草稿、晚到响应、跨项目隔离；缓存版本冲突不静默覆盖 |
| U08 | 分辨率系统解释菌体跨格数、源/障碍尺度、计算/预览格距与已知收敛证据，提供资源估计 | 不把经验格距当科学保证；耗时估计只来自可追溯观测 |
| U09/M11 | 轨迹、事件过滤/时间窗、谱系、候选参数差异和重复级置信区间 | 稳定实体ID；区间统计使用独立运行而非帧伪重复；样本不足明确不可用 |
| U10 | 模块说明、公式编号、符号、参数/端口双向定位，阅读与编辑入口分开 | 定位到真实节点和参数；来源/公式不作自动数学等价证明 |
| U11/U12 | document/view/run 与 commands 分离；保留紧凑专业软件工作区，完善鼠标/触控板/键盘/触屏 | 四尺寸、200%缩放、pointercancel/轻触拖动/单双指切换、滚动恢复；实体设备需实际测试才记通过 |

实体设备当前不能由浏览器尺寸模拟代替；有条件完成的自动化与浏览器验证逐项记录，真实手机/平板实测单独保留状态。离线编辑不等于离线求解；重新计算仍需安装内核和所需实现。
