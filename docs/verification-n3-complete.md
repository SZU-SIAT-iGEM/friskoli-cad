JavaScript 最终全量 **90 项通过、0 失败**。实际浏览器验证模板入口、科学图编辑、MCP 双群分支、保存/重开、真实 seed 批次、比较 CSV、死亡详情、观察轴、刷新查询与取消后的 partial 导出。四种尺寸为 1440×900、1024×768、390×844、844×390，最终截图均已目视检查，document 没有横向溢出。详细操作及 run ID 见[前端验收](verification-n3-ui.md)。

## 科学研究

主研究完成 **28 条件 × 8 seeds = 224 次**完整图运行，每次 10 s，0 失败，开始与结束的实现文件 SHA 一致。固定物理域、初值、浓度积分及源/材料尺度，分别改变 dt 和 grid；每个 seed 保存实际漂移、占用、到达/驻留、tumble 比例、摄取和物质账。失败不混入统计，未将“正漂移”设为程序通过条件。

额外 **9 条件 × 16 seeds = 144 次**运行均完成 30 s，0 失败，开始与结束的源码 SHA 一致。反向梯度方向对比 `(正梯度漂移−负梯度漂移)/2`：MCP 为 `+0.036325 ± 0.009883 SE µm/s`；B 原初值为 `−0.006695 ± 0.021908`，局部适应初值为 `−0.005467 ± 0.014037`。MCP 在追加条件下有正方向响应；B 当前参数效应未被样本分辨，不能称稳定反趋化，也不能将早先负差归因于启动瞬态。所有研究是构造场景的机制与数值证据，不能证明菌株实验性能。主研究已观察到 A 的时间离散敏感性，不能宣称整个耦合系统完全收敛。完整条件、均值/SD/SE 和同 seed 配对差见[研究报告](science/n3-comparison.md)及[科学说明](science/n3-mechanisms.md)。

整数数组修复改变实现文件指纹，原研究报告仍保留其实际运行版本。另用旧 wheel 和修复后源码进行 **43 对、86 次**隔离运行：覆盖全部 37 个原研究场景的 seed 0，以及 6 个真实分裂对照。**5,813 个提交边界**的完整 checkpoint 分量逐步精确相等，只排除必然随源码变化的 implementation lock 及其 payload hash；37 个原研究输入与最终轨迹/场指纹也匹配原报告，6 个分裂对照均从 8 变为 16 菌体。该定向等价检查支持保留原研究结果；没有把原报告改写成新版本重跑结果。

自然梯度回归使用材料模板，初始浓度为 0、无外加梯度、独立引诱物源释放率为 0、接触菌静止，普通酶/摄取参数保持不变。20 × 0.1 s 后材料共释放约 198.11135 分子当量；D=1 与 100 µm²/s 时场峰值约 0.00158918 与 0.000325153 µM，接受摄取约 0.612502 与 0.264677 分子当量，剩余释放物在同一外场。更快扩散得到更平的场；释放=场中剩余+实际摄取。该小例子验证物理机制的组合，不标定真实酶速率或扩散系数。

## 交付范围

N3 提供可计算、可编辑、可审查的科学模块与对照。参数未实验标定；MCP 的线性适应反馈、motor 到整菌事件率的映射、二维转角、几何阻挡、材料盒体与来源 health 规则都有显式适用边界。死亡剩余可用糖进入移出账，不自动释放回场；没有完整 ATP、碳、蛋白或膜材料预算。

N4 的目标/候选/原生设计包、N5 的静态 Wiki 与标准导出、N7 的服务暂停续算没有被本次独立 checkpoint 提前宣称完成。实体触屏、真实触控板和软键盘未实测；浏览器尺寸模拟不等于实体设备验收。
