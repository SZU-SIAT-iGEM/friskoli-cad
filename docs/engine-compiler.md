# 行为图编译器 · 阶段 3a

图编译器接收行为图和模块声明，先执行[协议检查](protocol-0.1.md)，再生成一份不可变的执行计划。计划保留每个节点的模块版本、所属环境或菌体组、参数来源、输入来自哪个端口，以及该输入读取本步还是上一步。

执行顺序按相位、`same_step` 依赖和节点 ID 确定。相同输入每次得到相同顺序；`previous_step` 连线保留在计划中，但不让本步形成环。读取上一步的输出必须在 `t=0` 已有初值。

在[常量场示例](../examples/protocol/graph.json)中，计划顺序是 `field → sampler → display`。换用[扩散场声明](../examples/protocol/graph-diffusion.json)后，`sampler` 的输入连接保持相同。此时编译器只确定“谁先运行、数据从哪里来”，尚未计算浓度、蛋白拷贝数或菌体运动。

下一段开发将建立模块执行接口、环境场与单菌体状态存储。首个可运行例子要让菌体读取浓度，产生有单位的摄取通量，再让环境场据此变化，并记录每个菌体的变化。数值方法和守恒检查将在该例子中明确说明。
