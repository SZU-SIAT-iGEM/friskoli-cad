# 工作区操作

第一版的正式流程为 Project 0.6 → Task 0.6 → Frame 0.2 / 数组 → 回放与研究包。界面默认英文，Settings 可切换中文。欢迎页载入当前预设，顶部 Run 提交冻结输入。当前范围以[支持矩阵](first-release/support.md)为准。

Space 编辑人口初态、几何和环境对象；Workflow 连接模块与时间边；Design 生成候选、分批运行、比较及导出；Results 读取已提交数据。正在运行的任务独立于当前草稿。Runs 显示任务状态，Data 显示内核记录的指标与时间曲线。

时间轴按需取保存帧，有界缓存。播放、切帧和相机操作不推进求解器。选中菌体可读 ID、位置、尺寸、状态与轨迹。全域视角对很小的菌体显示最小 4 px 位置标记；Focus cell 放大真实胶囊几何，标记不参与碰撞或科学状态。

鼠标拖动控制相机，滚轮缩放；触控模式中单指平移、双指缩放，Orbit 工具切换旋转。轻触选择与拖动分开判断。键盘可切帧，面板可滚动。浏览器尺寸模拟及手势逻辑检查不等同于实体手机实测。

File → Open 接受当前项目、Workspace 0.7 和原生 .friskoli 包。File → Export 的 portable research package 带冻结输入、指标、帧、hash 和请求的数组。结果可重开；求解或续算仍需要相同版本的软件和相应执行资源。静态 Wiki 只播放预计算数据。
