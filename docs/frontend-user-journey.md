# 前端用户历程笔记

状态：设计记录，尚未实现界面。这里记录用户从建立场地到检查结果需要看见的信息；数值能力的实际进度以 [PROGRESS.md](../PROGRESS.md) 为准。

## 建立场地与选择分辨率

1. 用户填写场地的实际 X、Y、Z 尺寸，并选择薄层或完整 3D。薄层必须填写实际厚度；界面解释薄层在 Z 方向使用一个浓度格。
2. 用户填写所用菌体的尺寸或选择带来源的菌株预设。菌体尺寸和环境格距作为两组独立参数显示，未提供尺寸时保持“未知”，不套用项目组菌株的值。
3. 用户可以修改 X、Y、Z 格距。界面同步显示格点数、每格尺寸、预计内存与计算负担，以及菌体在当前格距下大致占几格。薄层模式只显示一个 Z 格，但仍显示其实际厚度。
4. 推荐格距须写出理由：场地最小特征、源和障碍尺度、所选模块需要的空间信息，以及之后的收敛检查。若模块要计算菌体表面或局部接触而格距过粗，界面提示具体受影响的结果；中心点采样场景不使用“一格必须小于菌体”的统一禁令。
5. 用户可保存两个不同分辨率的运行设置，比较浓度、摄取和之后的轨迹。项目快照记录几何模式、场地尺寸、格距、时间步、模块版本与参数来源，使比较可复现。计算时间步与结果帧间隔分别设置。

## 连接模块与运行

用户从功能清楚的模块目录连接环境、感知、摄取和其他机制。更换一个实现时，界面显示端口形状、单位、物种、时间语义和状态迁移检查。接口兼容后可以保留其余行为图连接；内部状态不能迁移、科学假设发生变化或运行结果不可直接比较时，要明确告知用户。社区模块应有版本、声明、测试和参数来源，不能仅凭同名端口视为科学等价。

用户以后可为环境输入设置带单位的变化日程，预览每次变化的生效时间，并在回放中看到实际施加的控制。它的数值能力与物质账要求见[环境日程计划](environment-schedule-plan.md)；目前界面和运行器均未实现此功能。

运行前展示预计资源、已知模型适用范围和数值提示。运行中可选择一个菌体查看其稳定 ID、位置与模块状态历史，也可查看环境浓度场及菌体摄取造成的变化。播放与观察帧的频率不改变后端用于计算的菌体数量或数值时间步。

## 进入实现前的检查

- 先确定项目格式如何保存场地、分辨率和菌体尺寸，再接前端控件。
- 网格细化、时间步稳定性、运动时的场插值和守恒沉积经过测试后，界面才能给科学上的推荐值。
- 手机竖屏、手机横屏、平板和桌面分别检查设置面板、数值单位、警示文字和运行结果的可读性；浏览器模拟与实体设备验证分别记录。
