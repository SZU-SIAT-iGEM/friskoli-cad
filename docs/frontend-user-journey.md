# 前端用户历程笔记

状态：首版工作区已实现；这里记录用户从建立场地到检查结果需要看见的信息，以及仍待扩展的科学能力。数值能力的实际进度以 [PROGRESS.md](../PROGRESS.md) 为准，协议细节见[工作区协议](workspace-protocol-0.2.md)，实施顺序见[开发安排](development-order.md)。

界面默认英文，语言从 Settings 切换并保存在本地。整体采用专业软件的工作区、命令入口、视口、属性检查与时间轴。旧 WebUI 提供信息结构和使用经验的参考，实际代码与样式重新实现。首次进入结果工作区能看见真实示例的分裂帧、稳定 ID 和“只登记未计算”的氧；时间轴控制只改变观察的帧。

## 建立场地与选择分辨率

1. 用户从欢迎页新建、打开或恢复工作区。Space 现可编辑菌群体积块、数量、胶囊尺寸、固定随机种子和姿态；域尺寸和网格设置沿用项目中的协议字段。薄层必须使用一个 Z 格，界面在检查结果中显示容纳问题。
2. 用户填写所用菌体的尺寸或选择带来源的菌株预设。菌体尺寸和环境格距作为两组独立参数显示，未提供尺寸时保持“未知”，不套用项目组菌株的值。选择薄层时，尺寸已知的菌体需检查其当前姿态的 Z 向高度小于层高、上下边界在层内；尺寸未知时不能显示为已通过检查。
3. 用户可以修改 X、Y、Z 格距。界面同步显示格点数、每格尺寸、预计内存与计算负担，以及菌体在当前格距下大致占几格。固定场地采用整数格数时，界面显示由场地长度与格数算出的实际格距，不强制成倍数细分。还应说明均匀浓度场细分后每格浓度不变、单格分子数按体积减少、整场分子数保持一致。薄层模式只显示一个 Z 格，但仍显示其实际厚度。
4. 推荐格距须写出理由：场地最小特征、源和障碍尺度、所选模块需要的空间信息，以及之后的收敛检查。若模块要计算菌体表面或局部接触而格距过粗，界面提示具体受影响的结果；中心点采样场景不使用“一格必须小于菌体”的统一禁令。
5. 用户可保存两个不同分辨率的运行设置，比较浓度、摄取和之后的轨迹。项目快照记录几何模式、场地尺寸、格距、时间步、模块版本与参数来源，使比较可复现。计算时间步与结果帧间隔分别设置。

## 连接模块与运行

用户从功能清楚的模块目录连接环境、感知、摄取和其他机制。更换一个实现时，界面显示端口形状、单位、物种、时间语义和状态迁移检查。接口兼容后可以保留其余行为图连接；内部状态不能迁移、科学假设发生变化或运行结果不可直接比较时，要明确告知用户。社区模块应有版本、声明、测试和参数来源，不能仅凭同名端口视为科学等价。

Workflow 现可编辑已经登记的行为图：节点可拖动，端口会按形状、单位、物种和时间语义限制连接，参数修改可撤销；Evidence 页显示模块成熟度、科学角色、适用范围和登记说明。环境输入日程仍以项目数据导入，界面化日程编辑、局部入口与运行中替换环境仍在[后续计划](environment-schedule-plan.md)中。

运行前展示预计资源、已知模型适用范围和数值提示。运行中可选择一个菌体查看其稳定 ID、位置与模块状态历史，也可查看环境浓度场及菌体摄取造成的变化。[逐帧胶囊尺寸](growth-frames.md)与[分裂事件](adder-division.md)已有输出；前端画面应按菌体 ID 和结果帧呈现，不自行推算生长或分裂。播放与观察帧的频率不改变后端用于计算的菌体数量或数值时间步。

## 已实现与后续界面检查

- 项目格式已可保存场地、分辨率和可选的逐菌体初始胶囊尺寸，结果帧可表达尺寸变化与分裂。现有编辑器按事件建立新菌体、对未知尺寸作明确标记，并在 Check 面板列出薄层容纳问题。
- 运行提交保存不可变项目副本；Result 面板可在多个运行之间保留当前记录，查看事件、数据表、数量历史并导出 JSON/CSV。浏览器本地保存草稿用于恢复，不改变后端科学状态。
- 网格细化、时间步稳定性、运动时的场插值和守恒沉积经过测试后，界面才能给科学上的推荐值。
- 手机竖屏、手机横屏、平板和桌面分别检查设置面板、数值单位、警示文字和运行结果的可读性；浏览器模拟与实体设备验证分别记录。
- 当前前端只支持同步运行请求；异步任务、取消、断线恢复和更多环境/障碍对象需要在协议新增声明后再接入。
