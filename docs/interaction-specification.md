# Friskoli-CAD Product & Interaction Specification · 1.0

本页在 4b 交互规范基础上更新至 2026-10-01：N1 注册目录、N2 异步任务与 N3 趋化模板/指标/比较已交付。完整设计/候选流程和 Wiki 只读目标见[产品与交互设计](design/product-and-interaction.md)；具体实施范围以[开发安排](development-order.md)为准。

产品定位：构建、执行与分析单菌体生物仿真的可视化工作区。本规范采纳所附用户历程中的对象操作、可撤销编辑、明确反馈与输入/结果分离原则；附件中的建议不视为已经实现的功能或发布承诺。原 [Workspace/API 0.2](workspace-protocol-0.2.md) 合同继续保留；当前工作区见[注册目录与 Workspace 0.4](registry-contract.md)，运行合同见[任务服务](task-service.md)及[空间 profile](protocol/spatial-profile.md)。

## 工作区与常规操作

主导航固定为 Space、Workflow、Results。左侧呈现可操作对象/模块/运行，中央呈现空间或行为图，右侧呈现当前选择的属性。底部按需打开 Checks、Runs、Log、Data；Results 另有播放时间轴。采用本地无衬线字体、本地 SVG 图标、薄分隔线与紧凑面板，沿用旧版 WebUI 的深色、青绿色专业工作区，不复制其旧内核。

首次打开显示启动窗口，提供新建、打开、恢复草稿，以及按后端能力启用的几何采样、PTS、空间、生长分裂及 N3 六类完整图模板。关闭窗口进入无项目工作区，载入示例也不自动运行。New 采用空白三维场地；示例明确使用构造验证参数。界面默认英文，Settings 切换中文；模型 ID、单位与原始数据不翻译。

| 动作 | 可见响应 | 数据变化与撤销 |
| --- | --- | --- |
| 在对象库选择菌群后轻触视口，或从库拖入 | 创建可选体积块，打开数量/范围属性 | 一条撤销记录；尚未散布不能 Run |
| 选择、三轴移动/旋转/缩放，或输入数字后提交 | 预览变换；越界恢复并给出原因 | 每次拖动或字段提交一条记录 |
| Scatter population，含右键入口 | 初始菌体按 seed 分布，更新草稿显示 | 一个事务，不运行求解器；可撤销 |
| Duplicate | 复制块的初始化配置，生成新 ID，等待散布 | 不隐式复制行为模型；N3 新群可显式复制已有群的整条行为分支 |
| Hide / Lock | 隐藏编辑体积块 / 禁止其几何修改 | 不改变求解；可撤销。隐藏不删除菌体数据 |
| Delete population | 移除该组、所属图节点/连接/通道 | 一次可撤销事务 |
| Workflow 添加后端模块 | 在相位列生成卡片，可指定已散布的群组 | 只使用已声明默认值；缺参会阻止 Run，默认值来源可检查 |
| 连接端口 | 可拖线，也可先点输出再点输入；错误显示具体原因 | 校验形状、物理量、单位、物种、owner、时序与环；可撤销 |
| 编辑连接时序 / 节点参数 / 删除 | 更新右侧及连线显示；延迟连线为虚线 | 可撤销；删除节点同时清理失效通道引用 |
| Check | 底部显示初始状态有效或第一个错误 | 不求解，不改变草稿，不保证未来每步成功 |
| Run | 按精确 profile 能力提交异步任务；保留浏览与编辑 | 冻结输入、执行锁及输出计划，运行记录保留任务 ID |
| Cancel | 请求取消，等待服务确认终态 | 保留已公布的完整帧，partial 不作为完整结果 |
| 时间轴 / 播放 | 显示记录帧；亲子 ID 和尺寸来自后端 | 只改观察位置，不修改时间步或科学状态 |
| 选择菌体 / Data | 显示坐标、通道、帧历史、菌体总数曲线与表格 | 不补造缺席时刻数据；曲线只连接实际记录点 |
| Save / Export | 下载 Workspace / 运行 JSON 或统计 CSV（partial 显式标识） | Save 清除 Modified 标志；Export 始终取运行提交副本 |

## 输入、视图与焦点

鼠标拖动旋转视角，右键拖动平移，滚轮缩放；H 使用左键平移，O 使用单指旋转模式。触屏默认单指平移、双指缩放和平移；经过双指手势的抬指不能触发放置或选择。移动超过 5 CSS px 视为拖动，不执行轻触选择。Workflow 的卡片拖动、端口连接与画布滚动分开处理；取消的卡片手势恢复原位置。

V 选择，B 放置菌群，T/W 移动，E 旋转，R 缩放，M 测距，H 平移，O 旋转视角，F 适应，G 网格显隐。Ctrl/Cmd+S 保存，Ctrl/Cmd+Z 撤销，Ctrl/Cmd+Shift+Z 或 Ctrl+Y 重做，Ctrl/Cmd+Enter 运行。Delete 删除选中图对象或菌群，编辑文本时不拦截删除/撤销。Esc 关闭临时界面并退出放置/测距或待连接状态。

网格吸附使用当前最小格距，缩放吸附步为 0.1，角度吸附为 5°；格线只是编辑参考，不代表科学推荐精度。测距在经过场地中心且与相机垂直的视平面上选两点，显示距离及 XYZ 分量；它不是任意三维表面拾取或胶囊接触测量。

对话框使用模态焦点范围，常规控件保留键盘焦点提示；端口点击支持键盘 Enter。主要动作同时提供按钮，避免只有快捷键或右键才能操作。小屏从底栏随时打开对象/属性抽屉，抽屉独立滚动；横屏工具栏允许纵向滚动，关键面板入口留在底栏。布局使用动态视口和 safe-area；保留浏览器缩放能力。实体键盘、软键盘和设备安全区必须在后续实体设备验收中单独记录。

## 状态与异常路径

Workspace 状态：无项目 → 已加载草稿；操作产生 Modified → Save 下载后为已保存。浏览器自动恢复使用独立的 v2 存储键，不等于下载文件；存储失败要明确提示。打开/新建替换 Modified 文档前要求应用内确认，失败导入保留原文档。未知格式和过大文件在赋值前拒绝。

Run 状态：默认异步服务记录 queued、running、completed、failed、cancelled、interrupted；取消运行中的任务先请求取消，再等待服务确认。运行中修改草稿不影响冻结输入，迟到结果不会替换新草稿。浏览器重新打开后可按保存的任务 ID 恢复查询，服务重启后的旧活动任务标为 interrupted；已公布的完整帧可作为 partial 查看。旧结果带较早修订提示，播放停止与求解状态分开。`--sync-only` 保留原来的同步兼容路径。

物体库按当前 catalog 和 initializer adapter 启用对象。空间 profile 已提供障碍物、有限局部源和可降解材料盒，并执行胶囊运动接触检查；材料释放依赖显式表面酶和接触降解机制。纤维仍未实现，未知或不兼容对象不可用于求解。Task 0.3/0.4 可显示真实场及有限对象库存；旧 Task 0.1/0.2 不输出场数组。旧 spatial-unbiased-v1 不包含生长、分裂、外部日程或 MCP，PTS 信号不偏置运动。N3 chemotaxis-spatial-v1 的显式图包含 PTS/MCP 趋化、材料及生命周期分支，详情见科学合同。

M4 [checkpoint 文件](checkpoint-files.md)仅由 Python 库与 CLI 保存/恢复独立空间运行。任务服务的 pause/resume/checkpoint 仍为 false；草稿恢复、结果回放和项目导入均不提供 checkpoint 续算入口。

## N3 科学编辑与结果比较

Workflow 的模板列表可载入真实图；Evidence 展示公式、完整声明、参数当前值和 provenance。缺失参数不会由约束最小值或零填充。散布采用固定 seed 的保守外接球避碰，过密时给出失败并保留原草稿；未选中的初始化块在散布后不遮挡菌体。

Space 可编辑 observation 的轴与区域边界，以及执行 seed、输出帧间隔和是否输出场。1–8 个不重复 seed 依次运行一个冻结输入。Run 历史最多 32 条，比较中记录和当前批次记录不会自动删除；批次开始检查记录容量，持久化失败保留原列表及缓存。资源上限来自对应 profile 的 capabilities；步数输入遵循该上限，服务执行输入、输出和运行资源预算。当前 UI 不提供耗时/内存预估。

Data 使用后端记录的位移、区域占比、曾到达比例与驻留时间，显示定义、菌体通道曲线、材料/源库存与死亡采样明细。死亡表保留模块、health、hazard、概率与随机抽样，不推断唯一生物学死因。Task 0.4 死亡事件与明细必须逐一对应，并匹配冻结的模块、群组和 policy。

只有完成且有指标的运行可加入比较。域、观测定义、时长、步长和初始菌群数量必须一致；同一科学输入、后端、Task 合同及完整版本锁的不同 seed 归为同一变体，显示均值与样本 SD（n−1）。单次运行不显示 SD；重复 seed 被拒绝。比较 CSV 包含原始值、均值、SD 和完整版本锁。取消后的 partial 只查看/导出已公布帧，不能参与完整运行统计。

## 验收约定

每项功能都需核对成功路径、错误路径、撤销、保存重开与草稿/运行隔离。每个新增科学模块仍遵循 CONTRIBUTING 的公式、参数来源、单位、执行时序与回归要求。UI 改动不能宣称解决科学模型拟合、参数标定或数值适用性。

4b 原验收边界见[前端迁移验收](frontend-migration.md)；后续证据见 [N3 UI](verification-n3-ui.md)、[N2](verification-n2.md)、[空间验收](verification-spatial.md)及 [M4](verification-m4.md)。浏览器尺寸模拟、触摸事件测试、实体设备测试分开报告。协议与交互变化需同时更新本页、数据协议、示例、测试、README 与 PROGRESS；不再允许仅在会话里记录已实现状态。
