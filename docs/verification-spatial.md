# N3 空间基线验收

日期：2026-09-30。基线为 `n3-m0-m3`，分支 `feat/registry-contracts`。
本阶段增量保留旧执行规则；数值基础提交 `8d06ac0`，完整接入 `308cbb0`。

## 实际交付范围

- 新 Project 0.4 / Catalog 0.3 / Task 0.3，与前两套执行规则独立协商。
- 14 类空间/PTS 模块；障碍、实体底物、引诱物源使用已注册对象声明。
- 放置底物自动创建全局降解机制及共享物种场；必要角色的删除受保护。
- 有限的材料库存、接触范围和表面酶能力限制降解，产物进入养分场。
  多来源共享同一物种；PTS 请求、实际摄取和信号引用同一库存。
- 胞体/器壁/实体连续路径检查，独立随机流和事件时钟，失败整体回滚。
- 步初为空场时，新释放产物不会直接计入本步胞内；耗尽材料在提交后退出碰撞和场阻挡。
- 真实浓度数组和对象库存随完整帧公布。前端读取本次运行的冻结几何及所选帧库存。
- 实际注册的降解 adapter 可以替代默认模块；JSON checkpoint 锁定项目、代码、目录、依赖和随机状态。

科学语义、PTS/MCP 案例边界及几何近似见[空间说明](science/spatial-baseline.md)。
任务协议与帧结构见[Spatial profile](protocol/spatial-profile.md)。

## 测试与审查

数值基础 81 项测试、16 项子测试通过，涵盖有限几何、整段越障、同时运动、随机命名空间、
状态保存、守恒扩散、库存分配、接触酶预算和精度边界。新增精度检查按实际转移量约束误差，
防止大库存掩盖小转移的部分舍入损失；零摄取不再通过单位往返改写浓度。

前后端交叉检查使用真实 Catalog 和新示例，前端新增来源、底物后输出完整项目，
后端 `simulation_from_project` 与一步运行通过。此检查发现了新环境对象重复使用 `domain`
作为 owner ID 的问题，已修为各实体独立 ID，并加入回归断言。

专项检查还覆盖：先释放后摄取、多个材料共享每菌酶预算、材料耗尽及下一步扩散进入、
缺少/重复降解角色、已注册替代实现、错误 adapter 原子拒绝、checkpoint 恢复和字段配置校验。
旧单菌体帧版本和旧任务的无场输出约束不变。

上述专项数量包含在后续全套测试中，不重复相加。

## 完整回归

最终源码 **412 项 Python 测试、142 项子测试通过**，用时 109.83 s；**78 项 JavaScript 测试通过**。
Python 使用 `-B -m pytest tests -q -p no:cacheprovider`，测试临时目录与日志均在系统 Temp；
JavaScript 使用 `node --test --test-isolation=none tests/*.test.mjs`。

第一次全套发现旧 capability 断言只接受 Catalog 0.1/0.2，已改为精确核对新增的 0.3，
仍保留默认 legacy 目录与原结果检查。隔离安装又发现 execution seed 覆盖项目 seed 时
checkpoint 拒绝恢复，已改为使用保存的实际执行 seed，继续核对完整 RNG 与项目 SHA；
增加恢复后连续步骤完全一致的测试。上述最终结果在修复后执行。

开发期间的并发改码曾让任务的冻结源码摘要与新 worker 不一致，按预期失败；正式验收先冻结源码
并重启服务，再运行全部任务，没有关闭版本锁校验或把原失败任务修改为 completed。

## 保留限制

运动仍为无偏参考；PTS signal/motor bias 尚未驱动运动。没有完成 MCP 受体链、感知适应、
完整化学水解、连续侵蚀、营养生长或实验标定。不存在任务级 pause/resume。
局部采样使用包含菌体中心的体素；接触按步初几何，材料部分降解时保留盒体边界。
碰撞保护可能保守阻挡可行路径，不能据此报告壁面黏附或实际拥挤力学。

下一步在这个无偏对照上加入有证据的信号—运动连接，并建立 PTS 与 MCP 分开的案例、
多 seed 重复、迁移/富集指标和时间步/网格敏感性检查。
