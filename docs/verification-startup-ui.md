# 启动窗口与工作区一致性验收

日期：2026-09-29。实现依据[专业工具界面规范](design/professional-ui-reference.md)。本次修改位于 N1 之后，保留已有数值合同；不包含异步任务服务、科学模型接入或完整菜单系统。

## 实际变化

- 启动窗口改为项目命令与示例两栏；窄屏为单栏。沿用已有 SVG、无衬线字体、工作区色板和细边界，移除大宣传标题与预设插画卡片。
- 新建、打开、恢复、生长分裂示例、几何采样示例保持原功能；示例的未标定性质在窗口中可读。恢复按钮每次打开重新检查本地草稿，并同步说明文字。
- 只有真正从背景开始并在背景结束的点击才关闭弹窗；内部空白、从内部拖出与 pointercancel 不误关。Esc 不再修改背景工具；关闭启动窗口返回 New，关闭设置返回 Settings。
- 启动窗口内显示导入、恢复和请求错误，失败后可重试。加载期间禁用重复命令；关闭或重开窗口后，旧请求不再替换当前项目。Open 保留未保存草稿确认。
- 独立代码审查发现工具栏 Open 的旧文件读取分支也可能覆盖后续编辑，已加入导入 generation、项目 revision 和启动窗口 epoch 检查；过期读取取消并给出状态提示。
- 统一面板、属性行、数值输入及公式说明的尺寸；粗指针启动命令与关闭按钮至少 44×44 CSS px，工具栏容器不再裁切新增的 44px 按钮。

## 本轮验证

环境：本机服务 `127.0.0.1:18765`，Playwright CLI 的 Chromium 会话 `n1-ui`。交互测试使用单独测试页；布局使用独立浏览器 context。临时脚本和截图存放系统 Temp，没有添加运行输出或新浏览器依赖到仓库。

| 范围 | 结果与方法 |
| --- | --- |
| 启动与焦点 | 初始焦点 New project；5 个 SVG；X 返回 New；Tab 顺序保持在弹窗焦点范围内 |
| 关闭行为 | Esc 保留背景工具；内部空白不关；内部拖到背景不关；正常背景点击关闭；合成 pointercancel 取消关闭 |
| 草稿与示例 | 新建写入恢复草稿；重开提示更新；恢复得到相同工作区；两示例只加载、不自动 Run |
| 未保存保护 | New/example 与 Open 的取消分支保留已有草稿；用可计数的 `window.confirm` stub 验证调用及取消，不称为原生系统确认框验收 |
| 文件取消 | 合成 cancel 与空 change 事件保留项目和弹窗；没有操作真实操作系统文件选择器的取消按钮 |
| 文件导入 | 使用浏览器 File 输入加载 32 菌体工作区成功；坏 JSON 在弹窗内报错且可以重新导入。测试抑制原生选择器，实际读取仍走应用导入路径 |
| 请求失败/竞态 | 503 错误就近显示，可重试；拦截并延迟 registry 请求，关闭后新建项目，再放行旧响应，确认新项目不变 |
| 恢复失败/设置 | 损坏草稿报错；设置 Esc 恢复 Settings 焦点 |

上述交互套件 22 项断言通过，另有 2 项文件导入分支通过。浏览器无脚本异常。

独立审查之后再补 3 项真实浏览器检查：延迟 `File.text()`，分别在读取期间编辑当前草稿和新建另一个项目，释放读取后两者均保留；正常工具栏导入仍能载入 32 菌体工作区。为稳定覆盖竞态，测试控制文件读取完成时机并抑制原生文件选择器。此项验证针对本轮后补修正执行，不用先前的 22 项检查代替它。

尺寸矩阵为 **4 个尺寸 × 2 种语言 × 2 种指针模式 = 16 组**，全部通过：

| CSS viewport | 细指针启动窗口 | 粗指针启动窗口 |
| --- | --- | --- |
| 1440×900 桌面 | 600×355.4px | 600×378.1px |
| 1024×768 平板尺寸 | 600×355.4px | 600×378.1px |
| 390×844 手机竖屏 | 352×539.2px | 352×567.7px |
| 844×390 手机横屏 | 600×355.4px | 600×366px，内容内部滚动 |

每组检查：窗口位于 viewport 内、页面和弹窗无横向溢出、所有命令可聚焦并滚动到达、中英文关闭按钮的 accessible name 正确。粗指针启动按钮均达到 44×44px。无草稿的新 context 中恢复按钮禁用。粗指针横屏菜单/工具栏为 44px，竖屏双行工具栏为 92px。

已目视查看桌面启动窗口、手机中文启动窗口、桌面几何示例工作区截图，核对字体、边线、说明换行、控件和工作区的连续性。这是截图审查，不代表用户已经认可最终视觉。

20 项 JavaScript 回归、7 项服务与静态资源测试通过。第一次 Node 默认隔离模式因沙箱子进程权限报 `spawn EPERM`，改为同进程测试后通过；不计为代码测试失败后被忽略。历史 N1 的 119 项 Python 全套及 wheel 安装验证没有在本次重新执行，见[N1 原记录](verification-n1-ui.md)。
