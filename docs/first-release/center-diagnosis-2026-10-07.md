# 中心底物诊断：信号模块重写、开边界与释放量标定

2026-10-07。本轮的脚本与原始 JSONL 在 `runs/sensor-working-point/`（该目录按仓库惯例不纳入版本控制）。
下文数字均为本轮实跑结果，网格固定 `dx = 1 um`、`dt = 0.05 s`、时长 120 s，域 64×64×32 um。

## 一、`signal.pts_methylation` 重写

旧模块把 PTS 状态当作 MCP 的配体，用 `a = sigmoid(logit(a0) − g·e + ε_m(m−m0))` 描述感知复合体，
其中 `g = pts_energy_gain = 2` 没有物理来源。新结构：

```
C → J_uptake → PTS 状态 → A_sensory → CheY-P → 马达
                              ↑
                CheR/CheB ← 甲基化适应
```

| 旧 | 新 | 依据 |
| --- | --- | --- |
| `a = sigmoid(...)`，`g = 2` 自由 | `a = clip(a0 − e + g_m(m − m_min), 0, 1)` | 两个斜率由输入量程推出 |
| `pts_energy_gain`、`methylation_energy` | 删除 | 人工放大倍数 |
| `methylation_reference = 2` | `methylation_min = 0` | 零驱动参考态 |
| `ei_dephos_per_molecule = 0.01` 预设 | `= k_re / (copies·turnover / 2)` | EI 在 PTS 摄取半饱和处恰好半去磷酸化 |
| `adaptation_rate_s = 1` | `= span / tau_m`，`tau_m = 4 s` | 时间常数是声明的量，速率由它推出 |
| CheY `kp = 1, kd = 1`（τ_a = 0.75 s） | `kp = 15, kd = 5`（τ_a = 0.1 s） | 循环在基线处收支平衡、Y0 = Y_total/2 |
| `initial_*` 取零通量平衡 | 环境浓度处的适应固定点 | 消除每次运行的加载瞬态 |

两条耦合的推导：`e` 按定义是 0→1 的分数，甲基化量程是 `[methylation_min, methylation_max]`，
各自声明跨越完整活性区间 `[0, 1]`，于是 `da/de = 1`、`da/dm = 1/(m_max−m_min) = 0.25`。
可检查的推论：**甲基化量程恰好覆盖完整 PTS 区间**，满量程刺激仍能适应回基线而不被上下限钳住。

判据 0（`bias(y0) == a0`）移入模块 `self_consistent_motor_half`。副产品：对照组常数偏置现在
**恰好等于**反馈组适应态偏置 1/3，不再是手挑值。

传感器工作点（60 s）：EI 0.0019→0.649、甲基化 0.06→2.57、activity 0→0.565、bias 4e-66→0.84。
动态范围全开，不再饱和。

## 二、开边界：原先的场是闭盒

### 症状

细胞向壁面聚集，中心留不住。

### 根因

中心场的 `field.diffusive_local` 是**无通量闭盒**，没有汇。芯片预设本来就有
`field.boundary_exchange`（低侧汇、高侧源），中心一个都没有——这才是差别所在。核算：

- 域体积 131,072 um³；120 s 内细胞释放 8.11e7 分子
- 若全部留存 → 均匀浓度 **1.028 uM**
- 实测平台 **0.87–1.0 uM**，与细胞自身释放量吻合

即：该场不是底物降解形成的梯度，而是释放物在闭盒里灌平的结果。初始高斯只贡献 0.062 uM（占平台 6%）。
对比度随时间崩塌：

| t | 近表面 C (uM) | 远场 C (uM) | 对比度 | 远场 activity |
| --- | --- | --- | --- | --- |
| 30 s | 0.818 | 0.246 | 3.3× | — |
| 60 s | 0.800 | 0.470 | 1.7× | **0.333 = 适应基线** |
| 90 s | 0.963 | 0.679 | 1.4× | — |

t = 60 s 时各壳层的 `C_max` 均为 0.89–0.91，是平的。48 个细胞中 36 个位于 26–40 um 壳层，
该处 activity 恰等于基线，感知不到信号。

### 改动

六面互不重叠的边界板层（厚度 4 um、target 0 uM、rate 5/s，与芯片同一套一阶松弛），
精确切分边界壳层一次，因此角落不会被放松两次。同一时刻的场由
`min 0.246 / max 0.818` 变为 `min 0.000 / max 10.95`。

径向剖面（t = 60 s，4000 copies 版本）：

| 到表面 (um) | C (uM) | activity |
| --- | --- | --- |
| 0.5–1 | 1.266（max 10.8） | **0.126** |
| 2–4 | 0.671 | — |
| 6–8 | 0.268 | — |
| 12–16 | 0.064 | 0.333 |
| 20–26 | 0.011 | 0.343 |
| 26–40 | 0.0014 | 0.344 |

### 效果

同 seed 配对，接触层富集 `g(0–0.5 um)` 的 反馈/对照 比值：

| | 无汇 | 有汇 |
| --- | --- | --- |
| 比值均值 | 2.48 ± 1.04 (n=4) | **3.46 ± 1.30 (n=4)** |
| 反馈组 g 绝对值 | 11.01 ± **1.87** | 15.48 ± **0.03** |
| 反馈组接触量 (cell·s) | 137.3 ± **22.4** | 195.4 ± **0.84** |

**效应变大 59% 不是重点，重复性才是**：反馈组接触量的标准差小 27 倍，g 的标准差小 60 倍。
闭盒平台的高度取决于随机的接触历史；开边界后场收敛到由几何与释放速率决定的稳态剖面，
富集度成为可重复量。这对发布图比"数值更大"重要得多。

对照组在两种配置下**逐位相同**（42.1 = 42.1，70.8 = 70.8）：`signal.constant_bias` 不读浓度场，
改场对它没有任何影响。这同时说明对比是干净的，`aggregation.py` 没有通过旁路把场泄漏给对照组。

## 三、释放量：只有乘积可观测

### copies × kcat 是唯一的量

| copies | kcat | 释放总量 | C_max | C 总和 |
| --- | --- | --- | --- | --- |
| 4000 | 130 | 4.914e6 | 0.33688 | 15358.8 |
| 1000 | 520 | 4.914e6 | 0.33688 | 15358.8 |
| 400 | 1300 | 4.914e6 | 0.33688 | 15358.8 |
| **200** | **2600** | 4.914e6 | 0.33688 | 15358.8 |
| 8000 | 65 | 4.914e6 | 0.33688 | 15358.8 |

前五行逐位相同。所以因式分解只能按合理性选，不能按效果调。

### 200 copies 下的 kcat 门槛（60 s，有汇）

| kcat | C_max (uM) | 对比度 | activity 范围 |
| --- | --- | --- | --- |
| 10 | 0.038 | 66.6 | 0.330–0.336（≈ 全盲） |
| 100 | 0.398 | 132.9 | 0.101–0.355（有信号） |
| 300 | 1.292 | 95.1 | 0.000–0.592 |
| 2600 | 10.81 | 63.6 | 0.000–0.536（近表面饱和） |

门槛约在 `kcat ≈ 100/s`。

### 定稿取值与文献锚点

`RELEASE = {'baseline': (200., 2.5), 'strong': (200., 130.)}`。

- **200 copies**：单基因外膜展示构建体的合理量级。
- **kcat = 130/s（强释放臂）**：对应作用于**可溶底物**的糖苷酶，量级 10²–10³ /s。
  这正是 `material.degradable_box` 所代表的——该模块的 species 是可溶池，不是结晶纤维素。
- **kcat = 2.5/s（弱释放臂）**：进程性纤维素酶在**固体纤维素**上的量级是 0.01–1 /s
  （受链穿孔限制，表现为 burst kinetics）。两臂共用同一拷贝数、只降酶活。

若把强释放臂写成结晶纤维素上的 kcat ≈ 1/s，场**完全消失**（实测 C_max = 0.0000，
activity 恒等于 0.333，细胞全盲）。因此该因式分解必须连同"展示酶催化哪一步"一起声明。

### 定稿配置的实测

全部 4 seeds 完成后的三种配置：

| 配置 | g 比值 | 反馈接触量 (cell·s) | 反馈时间平均 bias | 平均 run 差 |
| --- | --- | --- | --- | --- |
| 无汇 @ 4000 | 2.48 ± 1.04 | 137.3 ± 23.3 | 0.3165 | 4.8% |
| 有汇 @ 4000 | 3.46 ± 1.30 | **195.3 ± 0.89** | 0.3465 | 3.5% |
| **有汇 @ 200** | **3.28 ± 1.39** | 181.1 ± 16.5 | **0.3334** | **0.0%** |

两种有汇配置的富集比值相当（3.46 对 3.28）。平均 run 只差 0–4.8% 而富集差约 3.5 倍，
因此"反馈组只是翻滚更少"不能解释该结果。

取舍在于重复性：4000 copies 的反馈接触量是 195.3 ± 0.89，200 copies 是 181.1 ± 16.5。
释放量小 20 倍后，场对随机接触历史的钉扎作用减弱，结果重新偏向噪声主导。
200 copies 的时间平均 bias 为 0.3334（基线 0.3333），是三个配置里翻滚总量配平最好的。
要在发布图上用 200 copies，需要增加 seed 数或延长时长来压散布。

## 四、顺带修复

`science_extensions.py:reservoir_exchange`：checkpoint 恢复后 `c.state['cumulative_net_input']`
是**只读 numpy 数组**而非 Python 标量，`cumulative += amount` 触发就地加法 →
`ValueError: output array is read-only`。芯片预设使用同一模块，此前一直存在该隐患。
改为先用 `float(np.asarray(...).ravel()[0])` 取出标量再相加。

同类就地更新在全仓只有这一处。

## 五、聚集机制的判读：滞留，不是远场定向漂移

按到表面距离分壳层统计细胞的平均径向速度 `dr/dt`（正 = 远离），反馈组与盲对照组同 seed 配对。
对照组一列在有无边界汇两种配置下**逐位相同**，再次确认它不读浓度场。

| 壳层 (um) | 反馈 | 对照 | 差 | 无汇时的差 |
| --- | --- | --- | --- | --- |
| 0.0–0.5 | −0.2046 | n/a | — | −0.0228（几乎无样本） |
| 1.0–2.0 | −1.1291 | −1.6757 | +0.547 | +0.853 |
| 2.0–4.0 | −0.8759 | −0.8762 | +0.000 | −0.040 |
| 8.0–10.0 | −0.4561 | −0.5434 | +0.087 | −0.090 |
| 12.0–16.0 | −0.1658 | −0.1549 | −0.011 | −0.034 |
| 16.0–20.0 | +0.2064 | +0.2486 | **−0.042** | +0.003 |
| 20.0–26.0 | +0.1810 | +0.2237 | **−0.043** | −0.014 |
| 26.0–40.0 | +0.1771 | +0.1384 | +0.039 | +0.017 |

**远场（> 16 um）的外流是几何/壁面效应**：反馈组与盲对照组同向、同量级，加汇后反馈组只比对照
少外流约 0.04 um/s（约为对照外流速率的 18%）。无汇时该差为 0.003–0.014，基本为零。

**接触壳层（0–0.5 um）加汇后才有样本**（−0.205 对无汇的 −0.023），细胞确实会停在接触层。

**1–2 um 处反馈组向内明显更慢**（−1.13 对 −1.68）：细胞贴表面做长 run、平行移动时 `dr/dt ≈ 0`，
这是滞留机制的签名。

结论：接触层富集主要来自**近表面滞留**（到达高浓度区的细胞进入长 run 状态并留下），
不是远场定向漂移。远场对反馈组和对照组近似等价。

## 六、未决

- **平均 bias 抬高**：有汇 @ 4000 copies 的反馈组时间平均 bias 为 0.3460（高于基线），
  是场被整体抽稀造成的非平衡瞬态，不是趋化驱散。200 copies 版本没有该现象（0.3323）。
- 远场滞留的 0.04 um/s 差异只有 2 个 seed，需要增加重复数才能确认它非零。
