# P2 研究流程证据

ModularSimulation 在原子提交前执行每步 cohort 观测，输出区域占比、沿轴平均位置、初始 ID 位移、到达、驻留、径向富集。边界包含在区域内，存活细胞与初始 cohort 分母分别记录；空群体使用 null。10–120 s 平均位置回归累计 n/Σt/Σy/Σtt/Σty，进入 checkpoint；120 s 前的完整窗口漂移为 null。固体释放按催化贡献分别归属菌群，累计转化量与按初始菌数归一化量独立于聚集指标。

checkpoint/v2 保存观测历史并重算当前指标核对。更早 checkpoint 明确拒绝。芯片脚本使用 snapshot.metrics，UI 显示求解器记录值；不从稀疏帧推断到达和驻留。Task 0.6 前端分页增加有界的指标历史，保留科学输入 hash。Design 增加模块化项目与转化/漂移目标，多 seed 的重复单位为 run。

可携带 Task 0.6 `.friskoli` 包由 run_delivery.py 输出：原始冻结 submission、实际 task/manifest、全部帧、包内相对数组路径、每段和整数组 SHA-256、checkpoint 和最终全分辨率场。读取不依赖原 TaskService。Wiki 支持此包及 Task 0.6 JSON。Design 导出补取完整历史与数组，避免把当前分页帧当成完整运行。主界面增加研究包导出与 Open 导入入口。

实际验证：

- modular 科学、采样、恢复及无旧依赖检查：通过，无依赖 skip。
- 连续 12 步与 5 步→保存→恢复→7 步的完整 checkpoint 相同。
- 真实 TaskService 分别每 1、7 步输出；两者最终 checkpoint 与直接引擎相同，包含 RNG、ledger、几何、数组与观测历史。
- 已关闭原服务后读取研究包，全部浓度数组与引擎逐元素相等；从该包生成静态 Wiki，原包字节保持不变，solver_included=false。
- 独立 NumPy 线性拟合与逐步观测回归一致；closed-region 到达与驻留手算检查通过。
- Node 验证分页指标、增量历史缓存、流式 JSON 中 task/status/completeness/输入 hash，以及多 seed 的 n 和重复 seed 拒绝。

命令：`python -m pytest tests/test_first_release_workflow.py tests/test_observations.py -q`、`node --test tests/first-release-ui.test.mjs`。实际分两次执行工作流测试：首次两个测试通过，包导出发现 checkpoint descriptor 没有 artifact_id；改为读取真实 href 后第三个通过。主界面的真人操作与长时研究、端到端耗时留在 P4 完成。
