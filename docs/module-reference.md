# 注册模块索引

更新：2026-10-03。以下内容由当前 `modular-spatial-v1` 注册目录核对，包含全部 73 个执行模块。名称便于阅读，ID/version 用于精确引用。基础模块和特殊科学模块共用同一执行接口。

系统时序见[完整运行图](system-execution.md)，科学假设与来源见[过程说明](science/modular-processes.md)。端口名后括号依次为 shape 与 unit；完整参数、公式、来源和状态在工作区 Catalog / Mathematical model 中读取。标注“结算后”的输出须由后续阶段读取，或显式使用 previous-step；阶段和端口检查不能证明任意连线在科学上合理。

MCP 与 PTS 均是特殊模型。PTS 重建版和简化版来自两份独立来源实现，模型边界见[来源说明](science/README.md)。
