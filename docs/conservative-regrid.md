# 浓度场的守恒重划 · 阶段 3f

对同一个物理场地换格距时，浓度场表示的是**每格体积内的平均浓度**。新格与旧格按实际重叠体积分配：

`新格浓度 = Σ(旧格浓度 × 新旧格重叠体积) / 新格体积`

因此每种物质的总分子数保持不变。均匀的 `10 µM` 场细分后仍处处是 `10 µM`；薄层 `5 × 5 × 1 µm³` 的一个旧格约有 `150,553.519` 个分子，分成四个 `2.5 × 2.5 × 1 µm³` 新格后，每格约 `37,638.380` 个。非均匀场会按重叠比例混合，不会凭空增加物质。

格数无需成倍数。例如长度 `10 µm` 上的两格浓度为 `[0, 12] µM`，改成三格后为 `[0, 6, 12] µM`：中间新格横跨原来的两格，各占一半，总分子数不变。[运行示例](../examples/runtime/remap_grid.py)同时展示四等分和两格到三格：

```powershell
$env:PYTHONPATH='src'
python examples/runtime/remap_grid.py
```

当前 [remap_concentration](../src/friskoli_cad/engine/regrid.py) 适用于相同薄层或相同 3D 几何、物理 XYZ 范围相同的均匀直角网格。每个方向可取任意正整数格数，实际格距等于场地长度除以格数；例如希望在 `20 µm` 宽度上使用约 `3 µm` 格距，可选 7 格并明确显示实际格距 `20/7 ≈ 2.857 µm`。无需强制 2、4、8 倍细分，也不允许悄悄改变场地长度。

此工具只转换一个物种的浓度数组。其他物种可分别转换；它不会迁移菌体状态、模块内部状态或一次正在运行的仿真。粗格合并会丢失细节，之后再细分也不能恢复原来的局部梯度。守恒重划解决的是**同一场地换网格时如何继承已有物质**；菌体从哪些格点感知和消耗物质由另行实现的[空间耦合模块](box-support.md)决定。
