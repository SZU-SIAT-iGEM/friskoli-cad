# 项目物种目录与环境输入日程 · 阶段 3k

[完整项目快照](../examples/runtime/scheduled_inputs.project.json)把场地、初始菌体、行为图、运行元数据、物种目录和外部输入日程保存在同一份 JSON 中。项目格式 `project_version: 0.1.0` 独立于图和模块仍使用的共享协议 `protocol_version: 0.1.0`；两个版本号各管自己的格式。旧版行为图和 `field.local_inventory` 的 `1.0.0`、`2.0.0` 可以继续按原有方式运行。

物种目录给每种物质声明初始浓度、`uM` 单位和来源。新环境模块 `field.local_inventory@3.0.0` 从目录读取初始浓度，避免在该图的多个位置重复声明。运行前会检查图中各物种引用均有登记、每种实际参与计算的物质最多有一个浓度场，日程对应一个同物种的输入模块。只登记、不在行为图中配置场或输入模块的物质，不生成格点数组，也不参加每步计算。目录仍需在创建运行时读取和校验一次。

当前[双物种示例](../examples/runtime/scheduled_inputs.project.json)为检验独立物质账，**明确接入了氧的浓度场与输入日程**，所以氧会参与计算。若项目只登记氧，移除图中的 `oxygen_field`、`oxygen_input` 两个节点及其连接，并移除 `oxygen_feed` 日程即可；[对应测试](../tests/test_project_schedule.py)核对了保留氧登记项与完全不登记氧时，执行节点、基质浓度和逐菌体结果一致。登记的初始浓度本身不会让氧自动保持恒定；将来若某模块需要固定氧浓度，仍要明确接入参数、常量来源或恒浓度环境实现。

## 外部输入如何生效

每个日程指定物种、`whole_domain` 作用范围和 `uM/s` 输入速率，并按时间递增列出变化点。首个变化点是 `t=0`，可选重复周期。正值代表向整个场地加入物质，负值代表从场地移除物质；两者都按速率累计，没有直接把浓度改写为目标值。当前只有均匀全域输入，局部入口和瞬时投料需另行定义模块及空间范围。

在时间步 `[t, t+Δt)` 中，`t` 边界上的新速率立即生效；`t+Δt` 边界上的变化留到下一步。若变化点严格落在一步内部，运行器拒绝整步，时间、浓度和菌体状态均不推进。这样保存的日程不会因所选时间步被悄悄延后。运行快照里的 `source.*.external_rate` 表示**刚完成的时间段**实际用过的速率；初始快照还没有完成时间段，因此记为零。要读出每次速率变化的来源，可用项目快照中的日程 ID、时间和 `provenance` 对照。

新图把日程模块 `source.scheduled_uniform_rate@1.0.0` 的 `external_rate: field.scalar, uM/s` 接到环境模块。环境按以下规则推进：

```text
C(t+Δt) = C(t) + Δt × [扩散率 − 菌体摄取率 + 外部输入率]
```

环境输出本步的 `external_flux: molecule/s` 和逐格累计的 `cumulative_external: molecule`；负速率形成负的外部净输入。当前例子中，扩散在封闭边界内守恒，因此对每种物质可核对：

```text
当前场分子数 = 初始场分子数 + 累计外部净输入 − 累计菌体摄取
```

氧没有接菌体摄取模块，该项为零。若外部移除或菌体摄取会使某格浓度为负，整个时间步报错并保持原状态。

## 可复现例子与范围

在仓库根目录运行：

```powershell
$env:PYTHONPATH='src'
python examples/runtime/run_scheduled_inputs.py --geometry thin_layer
python examples/runtime/run_scheduled_inputs.py --geometry volume
```

例子从 `10 uM` 基质和 `5 uM` 氧开始；基质在 `0.5–1.0 s` 接受 `0.2 uM/s` 的全域输入，每 `1.5 s` 重复；氧只在 `1.0–1.5 s` 接受 `0.1 uM/s` 的外部输入。菌体仅按原有示例律摄取基质。薄层第一次基质输入段累计增加约 `12044.28` 个分子，3D 在该示例场地增加约 `180664.22` 个分子；差别来自场地体积。数值、菌体参数和氧的名称都只供接口验证，不代表实验方案。

测试覆盖两种几何、独立物种物质账、重复与无变化日程、负速率移除、时间边界对齐、浮点时间步、内部变化点拒绝、错误单位与物种、过量移除回滚，以及由同一项目快照重复运行得到相同结果。当前尚无非均匀输入区域、瞬时投料、运行中环境模块状态迁移或性能基准。
