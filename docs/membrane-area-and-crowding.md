# 膜面积与拥挤生长：设计记录

状态更新：2026-10-01。膜材料与拥挤生长仍是待实现设计。下文“当前”指 legacy 的演示性增长/分裂：有胶囊总长 `L`、直径 `d`、位置与朝向，分裂按几何体积平均分配，未接入膜材料账或拥挤力学。新空间 profile 已有胶囊碰撞保护和面积读数，但未接入生长/分裂；见[空间基线](science/spatial-baseline.md)。这里的几何阻挡不代表真实接触力或挤压响应。

## 能由现有几何算出什么

对当前的理想胶囊，外表面积 `A = πdL`，体积 `V = πd²(L − d/3)/4`。面积是**派生的几何量**，目前既不保存为状态，也不限制生长。[现有等体积分裂](adder-division.md)令两个子菌直径仍为 `d`、长度各为 `(L + d/3)/2`，因此两个子菌的总面积是 `A + πd²/3`。示例中分裂前 `L = 3.0 µm`、`d = 0.8 µm`，几何面积从约 `7.54 µm²` 增至约 `8.21 µm²`，增加约 `0.67 µm²`。固定直径、等体积与几何面积完全不增这三个要求，不能同时套用在当前的两个完整胶囊上。

几何面积不等于可用的膜材料。后续如果研究受体负载，应按所需的膜区室保存膜材料或可用面积，以及受体拷贝数、占据密度与分布；分裂时这些**物质数量**应按声明分配，新合成与消耗有单独的来源。几何面积由尺寸推导，材料库存由具体合成、周转模块更新。对有内外膜的菌体，趋化受体与外表展示也不能自动共用同一个面积库存。MCP 等趋化受体可能集中在局部膜区，整颗菌体的外表面积只能作为初始几何尺度，不能直接充当受体容量。[Harris 与 Theriot，*Cell* 2016](https://doi.org/10.1016/j.cell.2016.05.045)对表面积与体积合成的相对速率做了实验和模型研究；[Tsr 膜组装研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC156230/)显示趋化受体在内膜中成簇。

材料限制的接口安排在具体膜机制接入时定义：几何更新提出所需的新面积，膜材料模块可提供可用材料、新合成与分配规则；没有接入该模块时默认**不限制**面积，也不把缺省值解释为零库存。需要明确区分内膜、外膜或其他区室，以及面积与物质数量之间的换算和来源。当前仍没有这项接口或限制。

## 空间不够时目前会发生什么

同次分裂产生的两个理想胶囊沿长轴端对端接触。当前程序没有检查它们与其他菌体、障碍物或 XY 方向完整外形的重叠；中心在场地内即可，薄层另检查 Z 向容纳。生长模块也没有接触力，所以菌体可能穿过彼此或伸出 XY 边界。

当前若子菌几何无效、子菌**中心**出界，或已知胶囊放不进薄层，运行器报错并回退整个时间步。这里的“时间步”指一次 `step(dt_s)`：这个运行实例的时间、环境场、所有菌体尺寸与 ID 都保持调用前状态，调用方收到错误；不会自动重算其他菌体或重试。反复发生此类错误会反复做无效计算，因而不能把它作为将来拥挤环境里的日常受阻规则。当前不会只取消生长、自动分成更小的菌体，或把失败解释成生理抑制。若只是与其他菌体相交，当前甚至不会报错。

## 建议的实现顺序

1. 先完成[结果回放与项目编辑](development-order.md)，让几何变化和事件可直接检查，再进入碰撞工作。提供几何面积与体积的只读派生值，并检查胶囊与墙、障碍及其他胶囊的空间占用；不合法几何须明确报错，不能作为正常帧交付。
2. 碰撞阶段把“想生长或分裂”与“这一步能否安置”分开，区分可预期的空间受阻与数值非法状态。前者设计明确的位移、延迟或受抑结果，允许时间和已接受的环境变化继续推进；后者仍可拒绝整个 `step(dt_s)`。是否重试、是否拆分为子步以及代价如何，需要以具体场景和物质账测试决定，当前不预设自动重算。
3. 接入膜材料、受体和营养机制时，再按可选接口核算几何所需面积、可用材料和新合成量。是否允许变形、减速、停长或分裂延迟，由有适用范围的模块决定；不能从“碰撞发生”自动推断唯一的生物反应。

拥挤的真实反应依菌株、环境和施力方式而变。[受外力压缩的 *E. coli* 实验](https://doi.org/10.1038/srep11367)观察到明显变形，但平均分裂时间未显著改变；[受限微流控中的 *Caulobacter* 对照实验](https://pmc.ncbi.nlm.nih.gov/articles/PMC11238078/)观察到分裂间隔延长。这些结果支持把变形、延迟和生长抑制做成可选择且有适用范围的机制，不能为本项目直接选定统一参数。
