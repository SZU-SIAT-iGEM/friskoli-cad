# 膜面积与拥挤生长：设计记录

状态：待实现的约束设计。当前程序只有逐菌体的胶囊总长 `L`、直径 `d`、位置与朝向；分裂按几何体积平均分配。没有膜材料库存、膜面积限制、菌体间接触或挤压响应。此页把这些不同的问题分开，避免把一次数值失败解释成生物抑制。

## 能由现有几何算出什么

对当前的理想胶囊，外表面积 `A = πdL`，体积 `V = πd²(L − d/3)/4`。面积是**派生的几何量**，目前既不保存为状态，也不限制生长。[现有等体积分裂](adder-division.md)令两个子菌直径仍为 `d`、长度各为 `(L + d/3)/2`，因此两个子菌的总面积是 `A + πd²/3`。示例中分裂前 `L = 3.0 µm`、`d = 0.8 µm`，几何面积从约 `7.54 µm²` 增至约 `8.21 µm²`，增加约 `0.67 µm²`。固定直径、等体积与几何面积完全不增这三个要求，不能同时套用在当前的两个完整胶囊上。

几何面积不等于可用的膜材料。后续如果研究受体负载，应按所需的膜区室保存膜材料或可用面积，以及受体拷贝数、占据密度与分布；分裂时这些**物质数量**应按声明分配，新合成与消耗有单独的来源。几何面积由尺寸推导，材料库存由具体合成、周转模块更新。对有内外膜的菌体，趋化受体与外表展示也不能自动共用同一个面积库存。MCP 等趋化受体可能集中在局部膜区，整颗菌体的外表面积只能作为初始几何尺度，不能直接充当受体容量。[Harris 与 Theriot，*Cell* 2016](https://doi.org/10.1016/j.cell.2016.05.045)对表面积与体积合成的相对速率做了实验和模型研究；[Tsr 膜组装研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC156230/)显示趋化受体在内膜中成簇。

## 空间不够时目前会发生什么

同次分裂产生的两个理想胶囊沿长轴端对端接触。当前程序没有检查它们与其他菌体、障碍物或 XY 方向完整外形的重叠；中心在场地内即可，薄层另检查 Z 向容纳。生长模块也没有接触力，所以菌体可能穿过彼此或伸出 XY 边界。

当前若子菌几何无效、子菌**中心**出界，或已知胶囊放不进薄层，运行器报错并回退整个时间步：时间、环境场、菌体尺寸和 ID 都不推进。它不会只取消生长、自动分成更小的菌体，或把失败解释成生理抑制。若只是与其他菌体相交，当前甚至不会报错。

## 建议的实现顺序

1. 先提供几何面积与体积的只读派生值，并检查胶囊与墙、障碍及其他胶囊的空间占用。首次规则以报告冲突和拒绝不合法时间步为准，确保回放不会把重叠当作正常生长。
2. 再把“想生长或分裂”与“这一步能否安置”分开。无空间时先尝试经明确定义的位移或接触处理；仍放不下时，保留待分裂状态，不自行减小子菌尺寸。若选择抑制生长，应让时间与环境按已接受的通量推进，并明确记录被阻止的尺寸变化及原因。
3. 接入膜材料、受体和营养机制时，分别核算几何所需面积、可用材料和新合成量。是否允许变形、减速、停长或分裂延迟，由经过标定的模块决定；不能从“碰撞发生”自动推断唯一的生物反应。

拥挤的真实反应依菌株、环境和施力方式而变。[受外力压缩的 *E. coli* 实验](https://doi.org/10.1038/srep11367)观察到明显变形，但平均分裂时间未显著改变；[受限微流控中的 *Caulobacter* 对照实验](https://pmc.ncbi.nlm.nih.gov/articles/PMC11238078/)观察到分裂间隔延长。这些结果支持把变形、延迟和生长抑制做成可选择且有适用范围的机制，不能为本项目直接选定统一参数。
