# 数值运行与模块库规划

状态：目标设计及现有能力分类。本轮不改变求解结果，没有提供实验数据的参数保持未知。文中不设置未经验证的菌株常数、阈值或性能承诺。

## 1. 模块的粒度

模块是具有明确数学/算法含义、输入输出、状态和验证边界的计算单元。纯函数、ODE/PDE 子系统、离散事件规则、几何操作、统计观察器都可以成为模块。紧耦合方程组保留为可展开的复合模块；外层展示科学关系，内部由适合的求解器处理。

基础数值算子和科学机制使用同一合同，按角色分类。现有线性摄取、线性伸长、定时转向和长度 adder 是基础或探索性机制；数值测试通过不自动代表 Friskoli 科学模型已经标定。

## 2. 几何与场

体域、具有厚度的薄层、未来表面域必须区分。当前 thin-layer 仍有体积，µM 不能当面密度；二维画面不消除厚度的物理含义。网格分辨率、菌体尺寸、采样/沉积支持范围分别定义。

胶囊总长 L、直径 d、半径 r=d/2、圆柱段 h=L-d，要求 L≥d>0：

```text
V = π r² h + 4π r³/3 = π d² (L-d/3)/4
A = 2π r h + 4π r² = π d L
axis_extent_i = (L-d) |u_i| + d
```

u 为单位长轴方向，中心到边界距离至少为半个 axis_extent。选择平面运动的薄层需要限制轴向倾斜，不能靠自动缩小菌体来满足边界。未知尺寸不能通过实体接触检查。

保持直径的等体积分裂给出子体总长 `L/2+d/6`，两子体总面积比母体增加 `πd²/3`。所以等体积不代表膜面积不变。启用膜材料模块才结算材料，未启用时明确该机制未建模；子体仍需满足 L≥d，且外廓与接触配置合法。

容量不能仅用总体积相除。体积分数可做必要条件和预警，实际初始化需有限次数的空间采样、邻域检索和精确接触检测；记录 seed、算法、尝试预算和失败原因。任意三角网格导入另做单位、闭合性、法向、尺度和碰撞/网格化检查；显示网格不自动成为物理实体。首版只支持可验证的胶囊和简单障碍。

## 3. 库存与守恒

沿用现有 µM/µm³ 计算约定时，每格物质量为 `C × V × 602.214076 molecule`。单位转换承接[现有运行器说明](../engine-runtime.md)，未来变换内部单位须与旧结果对照。

不发生跨物种反应时，对每一种物质核查：

```text
Δ环境库存 + Δ菌体累计摄取
    = 外部净输入 + 内部生成 - 独立消耗
```

跨物种反应按化学计量检查守恒的元素、质量或声明的模型守恒量，不能要求每种反应物分子数分别不变。有限源库存减少须等于释放；理想储库显式记录补给。

采样与沉积声明匹配的支持区域/权重。跨格运动后，摄取的空间来源与环境扣除位置必须一致；多个菌体争用同域库存需统一结算，不能分别重复读取和消耗全库存。

负库存、非有限值、守恒残差超标时拒绝该步。不能把浓度直接截到零却保留全量摄取。若采用库存限制器，要作为显式数值策略记录，并将接受通量回传所有相关模块。容差由有量纲的绝对值与相对值组合，记录在求解设置中。

## 4. 时间推进与旧语义

现有显式路线用旧通量推进环境，新位置刷新下一段采样/通量，分裂后有刷新规则。迁移时标识 legacy execution semantics 并保留回归；不能在旧项目上悄悄改时序。

新版本建议以保守显式分步法建立一个独立、可验证的 reference profile：

1. 保存 t_n 已提交状态与 RNG；时间步不得跨越未处理的日程边界。
2. 在时间边界施加外部事件，形成该步初始场和状态。
3. 在 t_n 的位置/支持区域采样浓度、梯度；生成 `[t_n,t_n+dt]` 的速率与状态提案。
4. 同时结算扩散、源、反应、摄取；默认对非法库存拒绝整步。启用通量限制时，PTS 读取接受通量，环境扣除和菌体积分使用同一值。
5. 感知/适应读取规定时段的浓度或通量，产生该 profile 定义的信号；运动、生长和生命周期生成状态提案。
6. 检查空间接触、几何、硬约束及守恒。生理受阻由明确机制协商修订提案，涉及的营养/材料账也要一致；无法合法结算则整子步回滚，或由声明的自适应方法缩短 dt 重试。
7. 一次提交场、模块状态、位置、几何、事件、ID 分配与 RNG，再输出；生命周期改变后重建 entity 索引。

这是有离散误差的显式选择，不是通用而精确的生物时序。运动中的连续感知、强耦合 MCP/PTS、刚性反应或精确事件时间，需独立验证子步或耦合求解器。代数环不能靠随意排序解决。

计算 dt、保存帧间隔与播放帧率独立。观察器按必要的计算频率累积指标，可少存帧，不能漏掉未保存时刻的到达或死亡事件。插值只用于显示；跨分裂/出生/死亡边界不能生成不存在的细胞。

## 5. 稳定性与误差

现有均匀系数、无通量扩散的显式离散对应检查 `dt × Σ(D/Δx_i²) ≤ 1/2`，仅对实际有扩散耦合的轴求和。该式的适用条件见[无通量扩散](../no-flux-diffusion.md)，不能作为所有插件统一的步长规则。反应、运动跨格、碰撞和事件还可能要求更小 dt。

局部源、表面反应、复杂边界引入后，在固定物理域、源范围、初始物质量和观测定义下比较网格与时间步。物理支持宽度不随格距改变机制；收敛针对明确的指标和误差门槛，不以画面细腻程度判断。

流场先以有出处的外部速度场或简化模块接入，再验证平流的守恒与稳定性。导入反应器几何不代表已经求解流体方程，首版不承诺通用 CFD。

## 6. 接触、生长和死亡

区分：

- `blocked`：模型允许的受阻，例如延迟分裂或停止推进，必须说明营养/能量/材料去向。
- `invalid_state`：协议、数值或几何失败，回滚并报错，不算生物死亡。
- `death`：明确的生物或探索性规则触发，保存规则、参数、触发量、时刻和后续状态。

死亡后移除碰撞体、释放内含物、保留残体或停止摄取均需机制声明，不能凭前端删除使物质消失。低摄取可进入能量储备模型，也可由用户显式选择持续阈值 toy rule；默认不将一次低于阈值等同死亡。

继续支持 copy/split/reset，复杂状态提供独立的可审查迁移函数。计数的随机分割、浓度继承、分子量分配、几何和受体适应状态不能都平均处理。

## 8. 首个 Friskoli 科学包

逐项审查旧模型中的感知/适应、PTS 摄取信号、MCP 响应、运动映射；确切方程和参数由原代码、模型说明与数据对照决定，本规划不假造。包可同时包含模块、参数、图模板、对象类型和示例。

物种身份、可代谢性、受体识别和响应效应分别建模。负趋化由响应机制表达，浓度仍非负。PTS 转运/信号不能成为全部底物降解的注册器；“固体表面降解 → 可溶产物 → 转运/感知”可分别实现。科学依据见[关键判断与证据](decisions-and-evidence.md)。

接触型表面展示酶模板可以要求 `surface_enzyme_activity` 与接触；这是该模板的依赖。分泌酶、纯释放等模板另行声明，不全局规定所有降解都必须依赖表面酶。

## 9. 比较、标定与性能

预先定义指标、观察区域、时间窗和基线。到达率/时间、富集、停留、转化都有明确分母；未到达个体按未到达/删失处理，不填 0。对照为零时比值不可定义，报告绝对差和原因；失败/取消运行不混入完成结果。

每候选用多个独立 seed。配对 seed 可用于对照，但生命事件改变后不能假定随机轨迹仍一一对应。随机流按 run/模块/群组/实体分流，算法固定，回滚恢复 RNG。同环境检验可复现，跨硬件以事先规定的数值/统计容差比较。

拟合需要实验数据、误差模型、可辨识性和留出验证；界面复刻不等于科学标定。敏感性先在限定参数范围筛选，结论随指标、范围、模型版本保存，不能永久把某参数归为低敏感。WIKI 中的 2–4 天或 3–5 天不作为工程工期承诺。

资源预检覆盖活跃场×体素×dtype×工作缓冲、细胞状态、接触邻域、最大增长规模、帧频率和磁盘需求，并用实测修正。未用物种不分配运行数组。

分别测数值、I/O、传输和绘制。instanced mesh 改善显示，不会加速扩散或接触求解。GPU 仅给已实现且获益的批量算子启用，保留 CPU 对照；资源不足明确失败或经用户选择切换已验证实现，不悄悄减少菌数或网格。
