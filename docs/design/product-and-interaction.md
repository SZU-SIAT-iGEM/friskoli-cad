# 产品与交互设计

状态：目标设计，未实现部分按[开发与验收](roadmap-and-acceptance.md)推进。当前行为仍见 [1.0 交互规范](../interaction-specification.md)。

2026-10-01 当前实现：六套科学模板可展开编辑、参数证据可查、群组复制带完整模型分支、观察区域可设、显式 seed 批次与完整结果比较可用。候选设计生成和 Design brief 仍按 N4 实施；验收见[完整 N3](../verification-n3-complete.md)。

## 1. 用户任务先于工作区

保留 Space、Workflow、Results 三个主工作区；在它们之上增加项目级的 Design brief、Candidates 和 Export 动作，避免把全部设计工作变成行为图操作。

- **快速开始**：选择 Friskoli 示例或带适用范围的模板，看到目标、关键假设和少量必要参数。可随时展开全部参数。
- **专业编辑**：空白项目或现有项目，直接进入空间和图；未完成设计可以保存，运行前必须补齐必需输入。
- **设计任务**：目标指标、观察时间、目标区域、底盘/构建设定、可变参数及范围、硬约束、软目标、对照方案、参数证据和不确定性。没有填写目标的项目仍可作为模拟项目运行，不得生成“最优设计”的结论。
- **候选生成**：第一版按已确认的兼容规则作有限枚举；先预估候选数和运行预算，显示排除原因。有限集合中的较好方案不能称为全局最优。
- **比较**：同一目标与观测定义下比较候选及无趋化对照，展示效应量、随机重复和不确定性。无校准数据的模型标为探索性。

参数按“必须提供”“可用有来源的参考值”“待研究”分组。是否低敏感只对特定模型、参数范围与指标成立；没有相应敏感性结果时，不把未知参数自动归入参考值。科学缺省值必须显示来源与适用条件，演示数值保持 illustrative 标记。

## 2. 启动与两种交付模式

| 启动入口 | 本地完整应用 | Wiki 只读演示 |
| --- | --- | --- |
| 新建项目 | 空白或向导；先选域和模板 | 禁用并显示原因 |
| 打开、导入、最近项目、恢复草稿 | 可用；先检查版本与依赖；失败保留当前项目 | 禁用 |
| 从示例快速开始 | 导入可编辑副本；计算由用户发起 | 唯一项目启动入口，打开预计算结果 |
| 导入模型/参数整合包 | 预览类型、版本、来源、许可证、执行代码及依赖，再导入 | 禁用；不得加载上传的可执行插件 |
| 下载完整版本、硬件说明、帮助 | 可用 | 可用 |

Wiki 启动窗口固定说明：“当前为 Wiki 演示模式，没有连接计算内核。显示的是团队预先计算并公开的记录，可用于回放、比较和查看模型说明。需要修改设计并计算时，请下载完整版本；性能要求见对应示例的基准记录。”

“禁用其他所有按钮”限定为创建、导入和求解入口。示例载入后保留观察视角、选中菌体、播放、切换场、查看方程和证据、比较预置运行及导出公开数据，否则无法展示基本功能。界面始终显示 Demo 标识、计算版本和记录来源；不能把旧记录当作刚计算的结果。Wiki 构建不发出 `/api/runs` 或本地 API 请求，也不因探测到 localhost 就自动连接。

本地模式也通过 capability 结果判定后端状态。未连接时可以编辑已缓存且类型已知的草稿，但 Run 禁用并提供重连动作；不自动切换成演示数据。

## 3. 信息结构和布局

```text
文件 / 编辑 / 视图 / 工具 / 帮助   项目名 · 修订 · 模式 · 后端状态
Design brief / Candidates       Space | Workflow | Results       Check / Run
┌ 对象树与库 ───────┬ 中央视口 / 图 / 比较画面 ──┬ 属性 / 方程 / 证据 ┐
│ 搜索、过滤、分组   │ 选择、导航、编辑、比例尺    │ 单位、来源、适用域 │
│ 视图可见 / 锁定   │ 明确当前操作与取消方式     │ 诊断定位、帮助    │
└──────────────────┴──────────────────────────┴──────────────────┘
Checks | Runs | Log | Data       Results 时间轴 / 区间 / 事件过滤
状态栏：模拟时间、当前选择、计算/播放状态、加载与资源信息
```

沿用现有深色、青绿色、紧凑专业工作区；正文和数值使用易读的无衬线字体。视觉改进服从信息层级：重要数值有单位，禁用入口有原因，错误不只靠颜色，科学未知不显示成零。全局导航只出现一次；把常见命令放到工具栏，完整命令仍在菜单内。

对象库按功能分组：菌群、化学源、实体底物/表面、障碍、观察区域。Workflow 模块库按“读取/采样、输运、摄取、感知、运动、生长、事件、统计”等功能组织。测试模块默认收进“基础/教学”，显示一句用途、一张小示意和最小示例，不把工程测试律包装成经校准机制。

## 4. Space：放置、散布和约束

### 对象放置事务

选择对象类型 → 预览位置 → 属性弹窗/侧栏 → 确认创建。预览不写入科学输入；Esc 取消。已登记且有证据的模板可带入默认值；缺少求解必需参数时，“保存为草稿”仍可用，“准备运行”不能伪装通过。一次确认产生一条 undo 记录，包括初始化对象及其关联节点。

右键菜单和移动端“更多”菜单使用同一个命令目录，按 capability、选择类型与文档状态生成。定位到底面/顶面要以有朝向的几何外廓计算接触位置，不能把中心直接设到边界。定位到空间中心、按轴移动、复制、删除、重置初始分布都支持数字输入。

“建立梯度”分成三种明确动作：

1. 设置初始浓度分布；后续由已连接的输运机制演化。
2. 添加持续释放源；用户说明物种、释放律、速率单位、支持区域与库存。
3. 设置边界储库/通量；这是持续的边界条件。

选择预设时展示上述物理含义；不默默开启一个永久保持的梯度。“删除梯度”显示将删除的初始化/源/边界及受影响连接。

### 菌群的身份与选择

`population_id` 表示群组身份与共用配置，`placement_id` 表示初始化区域，`cell_id` 表示运行中的单菌体；三者不能混用。放置区域只是初始化工具，不是把一群菌强制粘在一起的实体。群组内部允许有带种子的参数分布与个体差异。

“散布到全域”使用域作为采样支持区域，记录 seed、随机算法版本、数量和排除区域；不会永久把一个透明大立方体作为可点击遮罩。散布成功后初始化体积块默认取消视口拾取，仅在对象树选中时画线框；个体选择通过显式 Individual 模式、点击循环/候选列表和对象树完成。群组身份不解散；子代仍可追踪到群组和谱系。

重新散布、改变数量或几何会显示哪些初始状态将被替换；默认只改草稿，不改既有运行。复制群组显式选择“复制初始化和关联图模板”，预览 ID 和引用重写，防止两个群组意外共享可写状态。

### 空间合法性

编辑时检查域、边界、薄层朝向、放置块和对象外廓；运行前由后端复核。硬几何模式检查胶囊与障碍/菌体重叠；中心点模式必须标注“不检查实体排斥”，不能宣称无穿模。容量预估只是提示；严格放置仍需要检测实际构型。有限次随机放置失败时报告请求数、已找到的数量和约束，默认整次散布不提交，可显式接受少量放置。

显示/隐藏、选择锁定只影响 UI；“不参与运行”是另一个明确科学动作，需要依赖检查和修订更新。测距显示采用的平面/表面及单位，现有视平面测量不冒充任意表面距离。

## 5. Workflow：读得懂的模型

节点卡片默认显示功能名、短 ID、关键输入输出、适用组和状态；展开后显示完整注册 ID/版本、参数、来源、公式和数值方法。复杂方程放进右侧 Mathematical model 页，卡片只展示主式；说明、公式编号、符号和端口可以互相定位。没有闭式方程的采样、碰撞、记录器等模块展示算法及不变量。

放置菌群时自动建立一个折叠的“群组数据”提供者，其位置、朝向、几何、派生面积/体积等输出按需展开；不自动铺开几十个节点。源对象自动绑定初始化/释放提供者，但不会仅因物种目录里有某物质就建立整场数组。

自动图片段记录 `generated_by`、`owner_object_id`、`template_version` 和覆盖项。用户可以打开内部结构或显式解除模板管理；刷新模板不得覆盖手改连线。删除对象预览依赖，可级联删除自动节点或保留可修复的悬空草稿。编辑语义在前后端共用合同测试。

连接需匹配形状、单位、物理量、物种、group/entity 对齐、坐标系、采样位置、时间角色及可选性。跨群组通过显式 aggregate/map/reindex 节点；标量广播通过有名称的广播节点。单位换算可建议，但必须成为可见转换，不做无记录的自动换算。

`same_step`、`previous_step` 采用不同线型和文字提示；一般用户选择模板时间语义，专业用户才能改。回边不自动创建可执行的代数环；需要求解环的方程组包装为声明求解器的复合模块。

“摄取低于阈值导致死亡”等规则节点默认作用于显式选中的群组。全局规则必须明示 `all_populations`。节点需说明瞬时阈值、持续时长或资源储备模型，以及所需证据；不能因为加入图就隐式改变所有菌体。

## 6. Check、Run 与结果分离

Check 汇总独立问题，按 Error / Warning / Info 分级，并区分 pass / fail / unknown / not_applicable。每项显示代码、具体对象/端口/参数、原因、预期值和定位/修复建议；修复建议由用户触发，不改后台数据。缺少关键值导致的后续检查标记 skipped，避免重复报几十个同源问题。

阻断项包括格式/依赖错误、不支持的物理机制、单位或实体对齐冲突、必需参数缺失、已选严格几何失败、无法解释的数值不稳定。超出校准范围、证据薄弱和可选约束未知通常为警告；若项目把它列为硬约束，则阻止宣布设计可行。静止/无趋化对照必须可以显式创建，不能因底盘不运动而一概拒绝。

Run 提交不可变输入，显示等待、运行、取消中、已完成、失败、已取消等任务状态。取消求解与暂停播放采用不同命令；刷新后查任务，不重新提交。任务运行中可继续编辑草稿，结果固定绑定原设计与版本，完成后不能覆盖新草稿。

## 7. Results 与 Compare

- 记录帧、插值显示和真实求解步清楚区分；采样间隔不冒充求解精度。
- 支持全域/截面浓度、薄层热力图、轨迹、细胞数、摄取、到达/富集/停留/转化指标、事件时间线。观察区域和分母定义随指标保存。
- 事件按稳定 ID 关联出生、分裂、死亡、脱附、接触、受阻和环境变化；“死因”显示模型规则代码、触发值、阈值、来源及模型假设，不当作实验确定的原因。数值失败不登记为生物死亡。
- 多运行比较并排显示候选差异、共同参数、对照、随机种子、重复次数和置信/不确定性区间；缺失或中止的运行单独标记，不拿未完成末帧比较成败。
- 用户可以浏览已提交的部分帧，但必须有 Partial 标识；报告和默认比较仅采用已完成运行。
- 导出前先给出内容和损失清单；原生设计包包含原始条件、版本锁、指标定义与证据，标准转换能力见[交付设计](delivery-and-migration.md)。

## 8. 多端与可访问性

桌面支持鼠标、触控板与键盘；触屏默认单指平移、双指缩放/平移，通过模式切换旋转。沿用并检验现有拖动阈值，双指变单指、pointercancel、焦点丢失和旋转屏幕不会误放置/误选择。只在活动画布内接管手势，面板维持正常滚动。

右键功能均有可见菜单，端口支持点击后连接，3D 位置支持数字编辑。对话框焦点循环，Esc 退出；文本框内不接管 Delete/Undo；数值字段有名称、单位、错误关联。小屏左右栏变成可独立滚动抽屉，软键盘出现后保留焦点字段和确认按钮；尊重 safe-area 和浏览器缩放。横竖屏切换保留文档、相机、选中项、展开状态和阅读位置。

验收分别记录手机竖屏、手机横屏、平板和桌面的尺寸模拟、手势逻辑测试、实体设备实测；本轮仅规定门槛，未完成这些新设计的设备验证。Wiki 的首次阅读指引与本地编辑指引分开，演示页不出现编辑教学。
