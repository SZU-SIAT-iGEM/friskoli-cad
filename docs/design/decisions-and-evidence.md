# 关键判断、修正与证据

日期：2026-09-29。原始设想保留在用户提供的 WIKI 文件，本页说明如何转成工程约束。本文是有限的架构与语义核查，不是 Friskoli 全部科学机制的系统性综述或标定报告。

## 设想如何调整

| 原设想或疑问 | 工程判断 | 处理方式 |
| --- | --- | --- |
| 是否全栈重做 | 当前已有编译、ID、守恒、几何、回放和迁移证据，整体弃用会丢失可验证基线 | 渐进重构；保留 Python/NumPy 和前端模块，优先拆状态与服务 |
| 协议必须全部重置 | 有些类型、执行与 metadata 确需新合同，但无须同时清零所有格式 | 合同族独立版本，旧语义 reader/adapter；新 schema 与迁移样例一起交付 |
| 引诱物浓度为负则负趋化 | 浓度是非负状态；趋避响应取决于感知机制和条件 | 响应模型单独声明；现象学 signed gain 只能是明确的 toy/适用域内模型，不能将负浓度编码为斥源。B1 |
| MCP 注册引诱物，PTS 注册底物 | 物种身份与机制分开；转运、感知和代谢作用可以重叠 | 物种目录统一，配体—受体及转运机制引用它。PTS 与趋化耦合有研究依据，但不等于全部营养/降解机制。B2 |
| 降解必须接触且有表面酶 | 可以作为本项目特定机制的合同，不能推广成所有降解 | 接触型、分泌酶、纯释放等模板分别声明依赖 |
| 群组散布后解体 | 初始化块可以消失，群组身份和谱系还需要保存 | 分离 population/placement/cell ID，初始化线框默认不拾取 |
| 容量由域体积限制 | 体积比不能保证实际无重叠放置 | 姿态/外廓、接触、采样失败和严格几何模式分别检查 |
| 每模块必须一条方程 | 数据读取、采样、事件和求解器还需要算法表示 | equation/algorithm/compound 分类，方程组可在模块内联合求解 |
| 代码声明与 LaTeX 等价即可 | 声明无法保证科学或数值等价 | 符号映射、离散方法、分析小例子、回归、收敛/统计验证、人工审核 |
| 每节点自己选 CPU/GPU，互不影响 | 节点共享状态、资源和依赖；device 转移也是成本 | 声明 supported backends，全图 planner 统一调度 |
| 一步摄取不足即死亡 | 仅能作为显式的简化规则，不自动成为生理事实 | 指定群组、持续时间/储备模型、规则依据；数值失败不计生物死亡 |
| 放置源自动生成梯度 | 初始分布、持续源和边界条件含义不同 | 三类动作分别显示，记录质量来源及维护方式 |
| 网页禁用所有非示例入口 | 符合只读 Wiki 定位，但观察动作仍需可用 | 禁用创建/导入/求解，保留回放、选择、比较与公开数据导出 |
| 统一合成生物学格式可完整导出 | 设计、动力学、实验描述和容器各有不同标准范围 | 原生无损包为主，各标准适配器说明支持子集与损失。S1–S5 |
| 低敏感参数可用默认值 | 敏感性依赖范围、输出和模型，不是永久属性 | 保存分析适用域；未知参数不自动低敏感，参考值必须有证据 |
| 限制越多越像 CAD | 检查需区分物理非法、缺证据、资源不足和有意的对照 | error/warning/info + pass/fail/unknown；合法简化/静止对照允许存在 |

## 外部依据

以下在 2026-09-29 查询；只使用官方规范或原始研究。它们支持边界判断，不直接提供 Friskoli 模块参数。

- **B1**：[Chen 等，Tsr 配体与斥避识别原始研究](https://pubmed.ncbi.nlm.nih.gov/37102165/)，DOI `10.1021/acsbiomedchemau.1c00055`。研究显示具体配体与受体条件能够改变吸引/排斥响应；据此将物种浓度和响应机制分开。
- **B2**：[Chemotactic signaling via carbohydrate phosphotransferase systems in Escherichia coli](https://pmc.ncbi.nlm.nih.gov/articles/PMC3409764/)。原始研究讨论糖 PTS 与趋化系统的信号联系，支持将运输与感知接口明确连接，而非将所有底物/降解归为 PTS。PMC 直接打开触发浏览器校验，本轮依据搜索索引可读取的摘要/正文片段；实施科学模型前需核对完整论文。
- **S1**：[SBOL 3.1.0 官方规范](https://sbolstandard.org/docs/SBOL3.1.0.pdf)。组件、特征、相互作用、序列及模型关联是设计交换依据；本文不声称全部 ABM 状态均可映射。
- **S2**：[SBML 官方规格目录](https://sbml.org/documents/specifications/)和[Spatial package](https://sbml.org/documents/specifications/level-3/version-1/spatial/)。核心与扩展 package 有各自范围；目标软件是否支持所需 package 必须验证。
- **S3**：[SED-ML 官方说明](https://sed-ml.org/)。用于交换模型引用、仿真设置、任务及输出，不自行提供求解器。
- **S4**：[COMBINE 官方 OMEX 规格入口](https://github.com/combine-org/combine-specifications/blob/main/specifications/omex.md)。归档容器与内容文件的标准兼容性是两件分别验收的事。
- **S5**：[NCBI GenBank feature table](https://www.ncbi.nlm.nih.gov/genbank/feature_table/)及[FASTA 格式](https://www.ncbi.nlm.nih.gov/genbank/fastaformat/)。用于真实序列与注释，不可由只有空间/运动参数的方案虚构序列输出。
